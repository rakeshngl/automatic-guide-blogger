Firecrawl‑Powered Web Scrape & Summarize Mini‑App

Build a minimal scraper‑summarizer in 45 minutes using the free Firecrawl Cloud API

Welcome to another official UVF IT build guide! In this tutorial you’ll create a tiny web‑scrape‑and‑summarize app inspired by Firecrawl’s powerful crawling engine, but we’ll keep everything on your laptop with the free‑tier Firecrawl Cloud API and a tiny Python Flask server.

The result is a minimal web UI where you paste a URL, the backend fetches clean markdown via Firecrawl, runs a quick extractive summary with the sumy library, and displays the result – all in under an hour.

Prerequisites & Gotchas

  • You need Python 3.10+ and pip; the guide assumes a Unix‑like shell (Linux/macOS or WSL on Windows).
  • The free Firecrawl Cloud tier allows 1000 crawls/month – enough for testing but not for heavy traffic.
  • Summarization is done locally with sumy; it’s simple extractive summarization and won’t match LLM quality.

Phase 2: Minimal data model (optional SQLite)

Define a tiny SQLite helper that stores a URL together with its generated summary. When the same URL is requested again we can return the cached markdown and summary instantly, saving API calls and money.

The helper provides two functions: get_summary(url) returns a cached entry or None, and save_summary(url, summary) inserts or updates the record. It’s deliberately small – under 25 lines – and uses Python’s built‑in sqlite3 module.

db.py

import sqlite3
from pathlib import Path

DB_PATH = Path('cache.db')

def _connect():
    conn = sqlite3.connect(DB_PATH)
    conn.execute('''CREATE TABLE IF NOT EXISTS summaries (
        url TEXT PRIMARY KEY,
        summary TEXT NOT NULL,
        fetched_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    )''')
    return conn

def get_summary(url: str) -> str | None:
    conn = _connect()
    cur = conn.execute('SELECT summary FROM summaries WHERE url = ?', (url,))
    row = cur.fetchone()
    conn.close()
    return row[0] if row else None

def save_summary(url: str, summary: str) -> None:
    conn = _connect()
    conn.execute('INSERT OR REPLACE INTO summaries (url, summary) VALUES (?, ?)', (url, summary))
    conn.commit()
    conn.close()

Phase 3: Core API – fetch & summarize

In this step we add a /scrape route to our Flask app. The endpoint receives a JSON payload with a url, forwards it to Firecrawl's /scrape endpoint, and then runs an extractive summary using the Sumy library. We return a compact JSON object containing the original title, raw content, and the generated summary so the front‑end can display it easily.

app.py

from flask import Flask, request, jsonify
import requests
from sumy.parsers.plaintext import PlaintextParser
from sumy.nlp.tokenizers import Tokenizer
from sumy.summarizers.lex_rank import LexRankSummarizer

app = Flask(__name__)
FIRECRAWL_API = "https://api.firecrawl.dev/v0/scrape"
FIRECRAWL_TOKEN = "YOUR_FIRECRAWL_API_KEY"  # replace with your key

summarizer = LexRankSummarizer()

@app.route('/scrape', methods=['POST'])
def scrape():
    data = request.get_json()
    url = data.get('url')
    if not url:
        return jsonify({'error': 'URL missing'}), 400
    # Call Firecrawl
    resp = requests.post(FIRECRAWL_API, json={'url': url}, headers={'Authorization': f'Bearer {FIRECRAWL_TOKEN}'})
    if resp.status_code != 200:
        return jsonify({'error': 'Firecrawl failed'}), 502
    payload = resp.json()
    text = payload.get('markdown') or payload.get('content', '')
    # Summarize (3 sentences)
    parser = PlaintextParser.from_string(text, Tokenizer('english'))
    summary_sentences = summarizer(parser.document, 3)
    summary = ' '.join(str(s) for s in summary_sentences)
    return jsonify({
        'title': payload.get('metadata', {}).get('title', ''),
        'content': text,
        'summary': summary
    })

if __name__ == '__main__':
    app.run(debug=True)

Phase 4: Simple UI

Now we create a tiny HTML page that lets a user paste a URL and see the summary returned from our Flask API. The page uses the Fetch API to POST the URL to /scrape and then injects the JSON response into a <pre> block for easy reading. No styling libraries are needed – just plain HTML and a bit of JavaScript.

index.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Firecrawl Scraper</title>
</head>
<body>
  <h2>Enter article URL to summarize</h2>
  <input type="text" id="urlInput" placeholder="https://example.com/article" size="60"/>
  <button onclick="runScrape()">Summarize</button>
  <pre id="result" style="margin-top:20px; white-space:pre-wrap;"></pre>
  <script>
    async function runScrape(){
      const url = document.getElementById('urlInput').value;
      const res = await fetch('/scrape', {method:'POST', headers:{'Content-Type':'application/json'}, body:JSON.stringify({url})});
      const data = await res.json();
      document.getElementById('result').textContent = data.summary || data.error || 'No summary';
    }
  </script>
</body>
</html>

Phase 5: Run & verify locally

Start the Flask server, then open the UI in a browser to make sure everything talks to each other. The server will listen on port 5000 by default; visiting http://127.0.0.1:5000/index.html loads the front‑end. Paste any public article URL (e.g., a news story) and you should see a concise three‑sentence summary appear below.

export FLASK_APP=app.py
export FLASK_ENV=development
# Replace with your real token
export FIRECRAWL_API_KEY=YOUR_FIRECRAWL_API_KEY
flask run
