Hosts File Switcher Web UI with Node.js & Electron

A minimal clone of Hosts Tray – switch hosts groups from a desktop UI

Welcome to another official UVF IT build guide. In the next 45 minutes you’ll create a lightweight hosts‑file switcher with a simple web UI, using Node.js, Electron and a tiny JSON store – inspired by the Hosts Tray project.

We’ll keep everything local, no external services, so you can run, test and extend it on any macOS or Windows machine.

Before you start

  • Node.js >= 18 and npm must be installed – older versions may lack ES‑module support.
  • The real Hosts Tray bundles a reverse‑proxy and auto‑generated certificates; our clone only edits the hosts file and does not handle HTTPS.
  • On Windows you need to run the app as Administrator to modify C:\Windows\System32\drivers\etc\hosts.

Phase 1: Scaffold the Electron project

Create a fresh npm project and add Electron as a dev dependency.

Add a minimal main script that opens a browser window.

mkdir hosts-switcher && cd hosts-switcher
npm init -y
npm install --save-dev electron@latest
mkdir src
cat > src/main.js <<'EOF'
const { app, BrowserWindow } = require('electron');
function createWindow(){
  const win = new BrowserWindow({width:800,height:600,webPreferences:{nodeIntegration:true}});
  win.loadFile('index.html');
}
app.whenReady().then(createWindow);
app.on('window-all-closed',()=>{if(process.platform!=='darwin')app.quit();});
EOF
cat > index.html <<'EOF'
<!DOCTYPE html>
<html><body><h1>Hosts Switcher</h1></body></html>
EOF
npm set-script start "electron ."

Phase 2: Define data model (hosts groups)

Store groups as JSON; each group is an array of host entries (IP and hostname).

The file lives next to the code and is read at startup.

{
  "work": [
    {"ip":"127.0.0.1","host":"api.dev.local"},
    {"ip":"127.0.0.1","host":"db.dev.local"}
  ],
  "personal": [
    {"ip":"127.0.0.1","host":"myapp.local"}
  ]
}

Phase 3: Build the UI & IPC logic

In this step we give the renderer process a simple HTML UI: a <select> that lists every group defined in *groups.json* and an Apply button. When the user picks a group and clicks the button we use Electron's ipcRenderer to tell the main process which group to activate. Keeping the UI tiny makes it easy to extend later – you could add edit/delete controls without touching the core logic.

The renderer script lives in *src/renderer.js*. It asks the main process for the list of groups, builds the dropdown, and wires the click handler. All communication is done through a named channel (apply-group) so the main process can stay in control of file‑system access, which is safer and works on all platforms.

src/renderer.js

const { ipcRenderer } = require('electron');

// Ask main for the list of group names
ipcRenderer.invoke('list-groups').then(groups => {
  const select = document.getElementById('groupSelect');
  groups.forEach(g => {
    const opt = document.createElement('option');
    opt.value = g;
    opt.textContent = g;
    select.appendChild(opt);
  });
});

// When the user clicks Apply, send the chosen group to main
document.getElementById('applyBtn').addEventListener('click', () => {
  const chosen = document.getElementById('groupSelect').value;
  ipcRenderer.send('apply-group', chosen);
  // optional visual feedback
  document.getElementById('status').textContent = `Applying ${chosen}…`;
});
4

Phase 4: Apply selected group to system hosts file

The main process now listens for the apply-group message. When it arrives we read *groups.json*, locate the entry that matches the requested group, and build a block comment that can be safely inserted into the system hosts file. If a previous UVF‑IT block already exists we replace it; otherwise we append the new block. This keeps the hosts file tidy and ensures only one group is active at a time.

All file‑system work lives in *src/main.js* so the renderer never touches the OS directly. The code works on macOS/Linux (/etc/hosts) and Windows (C:\\Windows\\System32\\drivers\\etc\\hosts).

src/main.js

const { app, BrowserWindow, ipcMain } = require('electron');
const path = require('path');
const fs = require('fs');

function createWindow(){
  const win = new BrowserWindow({
    width: 400,
    height: 250,
    webPreferences: { preload: path.join(__dirname, 'preload.js'), nodeIntegration: true, contextIsolation: false }
  });
  win.loadFile('index.html');
}

app.whenReady().then(createWindow);

// Helper to locate the hosts file for the current OS
function getHostsPath(){
  return process.platform === 'win32'
    ? 'C:\\Windows\\System32\\drivers\\etc\\hosts'
    : '/etc/hosts';
}

// Provide the list of group names to the renderer
ipcMain.handle('list-groups', async () => {
  const groups = JSON.parse(fs.readFileSync(path.join(__dirname, 'groups.json')));
  return Object.keys(groups);
});

// Main IPC handler that updates the hosts file
ipcMain.on('apply-group', (event, groupName) => {
  const groupsPath = path.join(__dirname, 'groups.json');
  const groups = JSON.parse(fs.readFileSync(groupsPath));
  const entries = groups[groupName];
  if(!entries){
    console.error(`Group ${groupName} not found`);
    return;
  }
  const blockStart = '#===UVF-IT-START===\n';
  const blockEnd = '\n#===UVF-IT-END===\n';
  const blockBody = entries.map(e => `${e.ip}\t${e.host}`).join('\n');
  const newBlock = `${blockStart}${blockBody}${blockEnd}`;

  const hostsPath = getHostsPath();
  let hostsContent = fs.readFileSync(hostsPath, 'utf8');
  const regex = /#===UVF-IT-START===[\s\S]*?#===UVF-IT-END===\n?/;
  if(regex.test(hostsContent)){
    hostsContent = hostsContent.replace(regex, newBlock);
  } else {
    hostsContent += '\n' + newBlock;
  }
  fs.writeFileSync(hostsPath, hostsContent, { mode: 0o644 });
  console.log(`Applied group ${groupName} to ${hostsPath}`);
});
5

Phase 5: Run, test and extend

With the UI and IPC wired up, launching the app is as simple as invoking Electron on the *src* folder. The window should appear, show the dropdown populated from *groups.json*, and let you apply a group. After clicking Apply, open your system hosts file and look for the #===UVF-IT-START=== block – it should contain the IP/host pairs from the selected group.

From here you can iterate: add a tray icon, persist the last chosen group, or even spin up a tiny Node HTTPS reverse‑proxy that reads the same groups file. The scaffold we built is deliberately minimal so you can experiment without fighting a heavyweight codebase.

# Install Electron locally if you haven't already
npm install electron@latest --save-dev

# Start the application (assumes your entry point is src/main.js)
npx electron src
