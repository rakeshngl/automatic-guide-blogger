Minimal AI Agent Server Clone

A lightweight TypeScript/Node.js server that mimics Opengeni's core agent routing

Welcome to another official UVF IT guide! In this quick‑fire tutorial we’ll build a minimal AI‑agent‑server inspired by Opengeni, using only free‑tier Node.js, TypeScript and SQLite. The result is a tiny HTTP API that accepts a prompt, stores it, and returns a canned “agent” response – enough to prototype and extend later.

We’ll keep the stack simple: Node 18+, express, better-sqlite3, and TypeScript. No external AI APIs are called, so you can run everything locally in about 45 minutes.

Before you start

  • You need Node 18+ and npm installed; the guide assumes a Unix‑like shell.
  • The real Opengeni orchestrates multiple LLM providers – our clone only returns a static mock response, so it’s not suitable for production AI workloads.
  • SQLite stores prompts in a file; concurrent writes are limited – fine for a demo but not for high‑traffic services.

Phase 2: Define the data model

Set up a tiny SQLite DB with a prompts table and helper functions to insert and fetch records. SQLite lives in a single file, so no external service is required and the data persists between runs.

The wrapper abstracts the raw SQL calls, exposing simple addPrompt and getAllPrompts functions that the rest of the server can use without worrying about connections.

src/db.ts

import Database from 'better-sqlite3';

// Initialise (or create) a SQLite file called `prompts.db`
const db = new Database('prompts.db');

// Ensure the table exists – id auto‑increments, prompt stores the raw text, created_at timestamps the entry
db.exec(`
  CREATE TABLE IF NOT EXISTS prompts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    prompt TEXT NOT NULL,
    created_at TEXT DEFAULT (datetime('now'))
  );
`);

/** Insert a new prompt and return its generated id */
export function addPrompt(text: string): number {
  const stmt = db.prepare('INSERT INTO prompts (prompt) VALUES (?)');
  const info = stmt.run(text);
  return Number(info.lastInsertRowid);
}

/** Retrieve all stored prompts ordered by newest first */
export function getAllPrompts(): {id: number; prompt: string; created_at: string}[] {
  const stmt = db.prepare('SELECT id, prompt, created_at FROM prompts ORDER BY created_at DESC');
  return stmt.all();
}
3

Phase 3: Build the API & mock agent

In this step we create a tiny Express server that will act like the AI‑agent router. The /agent endpoint accepts a JSON payload with a prompt, stores it in memory, and immediately returns a fake reply so you can see the round‑trip working. We also add a /prompt/:id GET route so you can fetch any saved prompt later, which mimics how a real system might retrieve conversation history.

src/server.ts

import express from 'express';
import bodyParser from 'body-parser';

const app = express();
app.use(bodyParser.json());

// simple in‑memory store
let nextId = 1;
const prompts: Record<number, string> = {};

// POST /agent – store prompt and return mock reply
app.post('/agent', (req, res) => {
  const {prompt} = req.body;
  if (typeof prompt !== 'string') {
    return res.status(400).json({error: 'prompt must be a string'});
  }
  const id = nextId++;
  prompts[id] = prompt;
  const mockReply = `Echo: ${prompt}`; // static mock response
  res.json({id, reply: mockReply});
});

// GET /prompt/:id – retrieve stored prompt
app.get('/prompt/:id', (req, res) => {
  const id = Number(req.params.id);
  const stored = prompts[id];
  if (!stored) return res.status(404).json({error: 'not found'});
  res.json({id, prompt: stored});
});

const PORT = 3000;
app.listen(PORT, () => console.log(`🚀 Server listening on http://localhost:${PORT}`));

Phase 4: Run locally

Now that the code is ready we’ll start the server with hot‑reloading so any changes to src/server.ts instantly restart the process. ts-node-dev compiles TypeScript on the fly and watches the files, giving you a fast feedback loop during development.

npx ts-node-dev src/server.ts

Phase 5: Verify & extend

With the server running, use curl to hit the new endpoints and see the mock behavior in action. Once you’re comfortable, you can replace the static mockReply with a real call to an open‑source LLM or external API, turning this scaffold into a functional AI agent.

# Test POST /agent
curl -X POST http://localhost:3000/agent \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"Hello AI"}'

# Assuming the response gave id 1, fetch it back
curl http://localhost:3000/prompt/1
