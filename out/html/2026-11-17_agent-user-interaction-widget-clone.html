Agent‑User Interaction Widget Clone

A minimal TypeScript/Node.js AG‑UI‑inspired widget

Welcome to another official UVF IT build guide. In the next 45 minutes you’ll spin up a tiny TypeScript widget that mimics the core of ag‑ui: a bi‑directional event stream between a mock AI agent and a web UI.

We’ll use plain Node.js, Express, and SQLite (all free‑tier) to keep the clone lightweight yet functional – perfect for beginners eager to see agents talk to apps.

Before you start…

  • Node >=18 and npm installed – older versions miss native ES‑module support.
  • The real ag‑ui handles token streaming, tool calls and authentication; our clone only sends plain JSON events over HTTP.
  • SQLite stores messages locally; in production you’d replace it with a proper DB or cloud store.

Phase 1: Scaffold the project

We start by creating a fresh folder and turning it into an npm workspace that understands TypeScript. Express will serve our API and static UI, while better‑sqlite3 gives us a tiny, zero‑config database. All dependencies are free and install in seconds.

The dev dependencies include TypeScript itself and ts-node-dev so we can run the code without a separate compile step, keeping the workflow simple for newcomers.

npm init -y
npm i express better-sqlite3
npm i -D typescript @types/express ts-node-dev

Phase 2: Define the data model

Our widget only needs to remember a stream of events – who sent them, what the payload was, and when they happened. We model this with a single SQLite table called events. The helper below opens the database, ensures the table exists, and exports simple CRUD functions that the rest of the app will call.

Using better‑sqlite3 means the API is synchronous, which is perfect for a small demo and avoids callback noise. The code lives in src/db.ts and will be imported by the server later.

src/db.ts

import Database from 'better-sqlite3';

// Open (or create) a local SQLite file
const db = new Database('events.db');

// Ensure the events table exists
db.exec(`
  CREATE TABLE IF NOT EXISTS events (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    direction TEXT NOT NULL,   -- 'agent' or 'user'
    payload TEXT NOT NULL,    -- JSON string
    timestamp INTEGER NOT NULL DEFAULT (strftime('%s','now'))
  );
`);

export interface Event {
  id?: number;
  direction: 'agent' | 'user';
  payload: any;
  timestamp?: number;
}

export function insertEvent(ev: Event): number {
  const stmt = db.prepare('INSERT INTO events (direction, payload) VALUES (?, ?)');
  const info = stmt.run(ev.direction, JSON.stringify(ev.payload));
  return Number(info.lastInsertRowid);
}

export function getAllEvents(): Event[] {
  const rows = db.prepare('SELECT * FROM events ORDER BY timestamp ASC').all();
  return rows.map(r => ({
    id: r.id,
    direction: r.direction,
    payload: JSON.parse(r.payload),
    timestamp: r.timestamp
  }));
}

Phase 3: Build API + mock agent

In this step we spin up an Express server that will serve our static UI files, accept user messages, and stream back agent responses using Server‑Sent Events (SSE). The server keeps an in‑memory array of events so new clients can catch up on past messages, and a tiny mock agent simply echoes whatever the user sent prefixed with "Echo:". By exposing a POST /message endpoint and a GET /events SSE stream we create the minimal back‑end contract required by the UI.

src/server.ts

import express from 'express';
import cors from 'cors';
import { json } from 'body-parser';
import { createServer } from 'http';

// Simple event type
type Event = { id: number; data: string };

const app = express();
app.use(cors());
app.use(json());
app.use(express.static('public'));

let nextId = 1;
const events: Event[] = [];

// POST endpoint receives user text, creates a mock agent reply, stores both as events
app.post('/message', (req, res) => {
  const userMsg = req.body.message?.trim();
  if (!userMsg) return res.status(400).json({ error: 'Message required' });
  const userEvent: Event = { id: nextId++, data: `User: ${userMsg}` };
  events.push(userEvent);
  const agentEvent: Event = { id: nextId++, data: `Echo: ${userMsg}` };
  events.push(agentEvent);
  res.json({ status: 'ok' });
});

// SSE endpoint streams all events and keeps the connection open for new ones
app.get('/events', (req, res) => {
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');
  res.flushHeaders();
  // Send past events
  events.forEach(ev => res.write(`id: ${ev.id}\n data: ${ev.data}\n\n`));
  // Listener for new events
  const interval = setInterval(() => {
    const newEvents = events.filter(ev => ev.id > (req as any).lastSentId || 0);
    newEvents.forEach(ev => res.write(`id: ${ev.id}\n data: ${ev.data}\n\n`));
    (req as any).lastSentId = events[events.length - 1]?.id;
  }, 500);
  req.on('close', () => clearInterval(interval));
});

const server = createServer(app);
const PORT = process.env.PORT || 3000;
server.listen(PORT, () => console.log(`🚀 http://localhost:${PORT}`));

Phase 4: Minimal UI

Now we create a tiny HTML page that lets a user type a message, send it to the back‑end, and display a running conversation. The page posts to /message and opens an EventSource on /events to receive both user and agent messages in real time. All styling is kept inline for simplicity, so you can focus on the data flow rather than CSS.

public/index.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>AG‑UI Minimal Clone</title>
  <style>
    body { font-family: Arial, sans-serif; margin: 20px; }
    #log { border: 1px solid #ccc; padding: 10px; height: 300px; overflow-y: auto; }
    #msg { width: 80%; }
  </style>
</head>
<body>
  <h2>Chat with Mock Agent</h2>
  <div id="log"></div>
  <input id="msg" placeholder="Type a message" />
  <button id="send">Send</button>

  <script>
    const log = document.getElementById('log');
    const sendBtn = document.getElementById('send');
    const msgInput = document.getElementById('msg');

    // Open SSE stream
    const source = new EventSource('/events');
    source.onmessage = e => {
      const p = document.createElement('p');
      p.textContent = e.data;
      log.appendChild(p);
      log.scrollTop = log.scrollHeight;
    };

    // Send user message
    sendBtn.onclick = () => {
      const text = msgInput.value.trim();
      if (!text) return;
      fetch('/message', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ message: text })
      }).then(() => msgInput.value = '');
    };
  </script>
</body>
</html>

Phase 5: Run & verify

With the server and UI in place, start the development server using ts-node-dev so changes reload automatically. Then open the page in your browser, type a message, and watch the echo reply appear instantly thanks to the SSE stream. This confirms the full round‑trip: client → POST → mock agent → SSE → client.

npm install express cors body-parser ts-node-dev @types/express @types/node
npx ts-node-dev src/server.ts
