Simple Multi‑Source Research Agent (Python Clone)

A minimal AI‑free research aggregator using Reddit, Hacker News, and Wikipedia

Welcome to another official UVF IT guide! In this build you’ll create a lightweight research agent that pulls recent posts from Reddit, top stories from Hacker News, and summaries from Wikipedia – a stripped‑down version of the last30days‑skill.

We’ll use Python, FastAPI, and SQLite on the free tier, so you can have a working prototype in about 45 minutes without any paid APIs.

Prerequisites & Gotchas

  • You need Python 3.10+ and git installed; the script uses public JSON endpoints – no API keys required.
  • The clone skips AI ranking and paid data sources; results are raw and un‑filtered.
  • Rate limits may pause requests if you hammer Reddit or HN – the demo fetches only the latest 5 items each.

Phase 2: Data model & fetchers

We need a tiny SQLite schema to store fetched items – an id, a source tag, a title, a url, and a JSON payload for any extra fields. The helper below opens the DB, ensures the table exists, and provides an async save_item function that the fetchers will call.

Next, we sketch async fetcher stubs for Reddit, Hacker News, and Wikipedia. They each return a list of dicts matching the schema; later phases will wire them into the API endpoint.

app/db.py

import aiosqlite
import json
from pathlib import Path

DB_PATH = Path(__file__).parent.parent / "research.db"

async def init_db() -> aiosqlite.Connection:
    """Create the SQLite file and the `items` table if they don't exist."""
    conn = await aiosqlite.connect(DB_PATH)
    await conn.execute(
        """
        CREATE TABLE IF NOT EXISTS items (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            source TEXT NOT NULL,
            title TEXT NOT NULL,
            url TEXT NOT NULL,
            payload TEXT NOT NULL,
            fetched_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
        )
        """
    )
    await conn.commit()
    return conn

async def save_item(conn: aiosqlite.Connection, source: str, title: str, url: str, payload: dict) -> None:
    """Insert a single fetched record into the DB.
    `payload` is stored as JSON text so we can keep extra fields without schema changes.
    """
    await conn.execute(
        "INSERT INTO items (source, title, url, payload) VALUES (?, ?, ?, ?)",
        (source, title, url, json.dumps(payload)),
    )
    await conn.commit()

Phase 3: API endpoints & startup

In this step we expose the data‑gathering logic through a tiny web API. The /collect POST endpoint will call each source‑fetcher, store the results in an in‑memory list, and report how many items were added. A second GET endpoint /articles simply returns the stored rows so the front‑end can display them.

We keep everything lightweight: FastAPI runs in a single process, the article list lives in a global variable, and we avoid a database for this minimal clone. This design lets you see the whole flow—from raw HTTP request to populated JSON—without any extra infrastructure.

app/main.py

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List
import asyncio

# Import the three fetcher functions you built earlier.
# They must be async and return a list of dicts with at least 'title' and 'url'.
from fetchers.reddit import fetch_reddit
from fetchers.hackernews import fetch_hackernews
from fetchers.wikipedia import fetch_wikipedia

app = FastAPI(title="Simple Multi‑Source Research Agent")

# In‑memory storage for collected articles
articles: List[dict] = []

class Article(BaseModel):
    title: str
    url: str
    source: str

@app.post("/collect")
async def collect():
    """Trigger all fetchers, de‑duplicate, and store results.
    Returns the number of new articles added.
    """
    # Run fetchers concurrently
    results = await asyncio.gather(
        fetch_reddit(),
        fetch_hackernews(),
        fetch_wikipedia()
    )
    new_items = []
    for source_name, items in zip(["reddit", "hackernews", "wikipedia"], results):
        for item in items:
            # Normalise each item to our Article model
            article = Article(title=item["title"], url=item["url"], source=source_name)
            # Simple deduplication by URL
            if not any(a["url"] == article.url for a in articles):
                new_items.append(article.dict())
    articles.extend(new_items)
    return {"added": len(new_items), "total": len(articles)}

@app.get("/articles", response_model=List[Article])
async def get_articles():
    """Return the current list of stored articles."""
    if not articles:
        raise HTTPException(status_code=404, detail="No articles collected yet.")
    return articles

Phase 4: Run locally & test UI

Now we spin up the FastAPI server and make sure the endpoints are reachable. The uvicorn command watches your code, so any change you make to a fetcher or the API will reload automatically—perfect for rapid iteration.

After the server is running, open the tiny HTML page provided in the next phase; it will call /collect to pull fresh data and then display the titles from /articles. This gives you an end‑to‑end test without any heavy front‑end tooling.

# Install dependencies if you haven't yet
pip install fastapi uvicorn aiohttp

# Run the API server (reload enabled for development)
uvicorn app.main:app --reload

Phase 5: Verify and extend

With the server alive, use curl or a browser to hit the endpoints and confirm JSON payloads appear. The provided index.html makes these calls for you and renders a simple list of article titles.

If you want to go further, add a query parameter to /articles?source=reddit to filter, or replace the static page with a React component that offers search and pagination. The scaffold is deliberately tiny so you can experiment freely.

index.html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8" />
    <title>Research Agent UI</title>
    <style>
        body {font-family:Arial, sans-serif; margin:20px;}
        button {margin-bottom:10px;}
        li {margin:5px 0;}
    </style>
</head>
<body>
    <h1>Latest Articles</h1>
    <button id="refresh">Refresh</button>
    <ul id="list"></ul>

    <script>
        async function collect() {
            await fetch('http://127.0.0.1:8000/collect', {method:'POST'});
        }
        async function loadArticles() {
            const resp = await fetch('http://127.0.0.1:8000/articles');
            if (!resp.ok) { document.getElementById('list').innerHTML = '<li>No data yet.</li>'; return; }
            const data = await resp.json();
            const ul = document.getElementById('list');
            ul.innerHTML = '';
            data.forEach(a => {
                const li = document.createElement('li');
                const aTag = document.createElement('a');
                aTag.href = a.url; aTag.textContent = a.title; aTag.target = '_blank';
                li.appendChild(aTag);
                li.append(' ['+a.source+']');
                ul.appendChild(li);
            });
        }
        document.getElementById('refresh').addEventListener('click', async () => {
            await collect();
            await loadArticles();
        });
        // Auto‑load on page open
        loadArticles();
    </script>
</body>
</html>
