No‑Server Daily Word Game Clone (Wordout)

Build a simple daily word puzzle with only HTML, CSS, and JavaScript

Welcome to another official UVF IT build guide. In the next 45 minutes you’ll create a minimal daily‑word game inspired by Wordout, using only static files and the browser’s local storage—no backend required.

We’ll scaffold a tiny project, generate a daily word list, wire up a guess‑checking UI, run it locally, and verify that a new word appears each day.

Before you start

  • You need Node ≥ 18 or any modern browser with ES6 support – the guide runs a simple static server via npx serve.
  • The clone skips the original’s word‑frequency scoring and multiplayer leaderboard; it only checks exact matches.
  • If you edit the word list while the page is open, you must refresh the browser to load the new data.

Phase 2: Load the daily word (model)

We compute a deterministic index from today’s date so every visitor sees the same word for a given day. By loading words.json and applying the index, the app knows which word to validate against.

The code runs in the browser, fetches the JSON list, calculates the index, and stores the chosen word in a global variable for later UI checks.

app.js

// app.js – load words and pick today’s word
let todayWord = '';
function dateHash(str){let h=0;for(let i=0;i<str.length;i++){h=(h*31+str.charCodeAt(i))>>>0;}return h;}
async function init(){const r=await fetch('words.json');const words=await r.json();const today=new Date().toISOString().slice(0,10);const idx=dateHash(today)%words.length;todayWord=words[idx];console.log('Today’s word:',todayWord);}
document.getElementById('check').addEventListener('click',()=>{const guess=document.getElementById('guess').value.trim().toLowerCase();const msg=document.getElementById('msg');if(!todayWord){msg.textContent='Word not loaded yet.';return;}if(guess===todayWord){msg.textContent='✅ Correct!';msg.style.color='green';}else{msg.textContent='❌ Try again.';msg.style.color='red';}});

Phase 3: Build the UI and guess logic (API/UI)

First we create a tiny UI: an input for the player's guess, a button to submit, and a div that will display feedback. The script fetches the daily word list from words.json, picks today’s entry, and compares it to the user's guess. When the guess is correct we store a flag in localStorage so the solved state survives page reloads. Finally we render either the input form or a congratulatory message based on that flag.

app.js

// app.js – UI rendering and guess handling
document.addEventListener('DOMContentLoaded', () => {
  const container = document.getElementById('app');
  const solvedKey = 'wordout-solved';
  const today = new Date().toISOString().slice(0, 10);

  // Load words list and pick today’s word
  fetch('words.json')
    .then(r => r.json())
    .then(words => {
      const todayWord = words[today] || Object.values(words)[0]; // fallback
      const isSolved = localStorage.getItem(solvedKey) === today;
      renderUI(isSolved, todayWord);
    })
    .catch(err => container.textContent = 'Failed to load words.' );

  function renderUI(solved, word) {
    container.innerHTML = '';
    if (solved) {
      const msg = document.createElement('div');
      msg.textContent = '✅ You solved today’s word!';
      container.appendChild(msg);
      return;
    }
    const input = document.createElement('input');
    input.type = 'text';
    input.placeholder = 'Enter your guess';
    const button = document.createElement('button');
    button.textContent = 'Check';
    const result = document.createElement('div');
    button.onclick = () => {
      if (input.value.trim().toLowerCase() === word.toLowerCase()) {
        localStorage.setItem(solvedKey, new Date().toISOString().slice(0,10));
        result.textContent = '✅ Correct!';
        renderUI(true, word);
      } else {
        result.textContent = '❌ Try again.';
      }
    };
    container.appendChild(input);
    container.appendChild(button);
    container.appendChild(result);
  }
});
4

Phase 4: Run locally

A static server is needed because browsers block fetch of local files for security reasons. The easiest way is to use the serve package that comes with Node – it serves the current directory over HTTP on port 3000 by default. Once the server is running you can open the page in any modern browser and the game will load the word list without CORS errors.

# Install a tiny static server (once)\nnpm install -g serve\n# Start the server in the project root\nserve . -l 3000
5

Phase 5: Verify and extend

Open http://localhost:3000 in your browser; you should see the input box and a button. Type the word for today (check words.json if you’re unsure), hit Check, and you’ll get a ✅ message. Reload the page – the success message stays because we saved the solved state in localStorage. To add new daily words, simply edit words.json with a new date‑to‑word mapping and restart the server to pick up the changes.

# No extra code needed – just refresh the browser after editing words.json\n# If you changed the file while the server is running, restart it:\npkill -f "serve ." && serve . -l 3000
