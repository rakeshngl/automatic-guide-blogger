PasteKit‑Style JSON/YAML Formatter

Format JSON, YAML & SQL privately

Welcome to another official UVF IT guide! In this quick‑fire tutorial we’ll build a minimal clone of PasteKit – a tiny web app that lets you paste JSON or YAML, formats it nicely, and returns the result instantly. No accounts, no cloud storage, just pure local processing.

We’ll use Node.js with Express and the open‑source js-yaml library, store snippets in an in‑memory array (so you can see the data flow), and run everything on your laptop in under 45 minutes.

Prerequisites & Gotchas

  • You need Node ≥ 18 and npm installed; older versions may lack native fetch support used in the demo UI.
  • The clone only formats data – it does not persist to disk or provide authentication, unlike the real PasteKit.
  • Running on Windows may require set PORT=3000 && npm start syntax; on macOS/Linux use PORT=3000 npm start.

Phase 2: Data model (in‑memory store)

The store module is a tiny in‑memory database that keeps each snippet in an array and hands out a monotonically increasing numeric ID. It exposes three helper functions – addSnippet, getSnippet, and listSnippets – which the API layer will call later. Because everything lives in RAM, the data disappears when the process stops, which is perfect for a demo clone.

Keeping the store isolated in its own file makes the rest of the code easier to test and reason about. Later phases will simply import this module and use its functions without caring how the data is kept.

store.js

// src/store.js
let nextId = 1;
const snippets = [];

/**
 * Add a new snippet and return its assigned ID.
 * @param {string} content – raw JSON/YAML string
 * @param {string} type – "json" or "yaml"
 */
function addSnippet(content, type) {
  const record = { id: nextId++, content, type, created: new Date() };
  snippets.push(record);
  return record.id;
}

/** Retrieve a snippet by its numeric ID. */
function getSnippet(id) {
  return snippets.find(s => s.id === Number(id)) || null;
}

/** Return a shallow copy of all stored snippets. */
function listSnippets() {
  return snippets.slice();
}

module.exports = { addSnippet, getSnippet, listSnippets };
3

Phase 3: Core API & formatter

In this step we expose a /format endpoint that receives raw text, determines whether it is JSON or YAML, formats it nicely, and stores the result in memory for later retrieval. Detecting the format lets us apply the right pretty‑printer: JSON.stringify for JSON and js-yaml for YAML. The endpoint returns the formatted string so the UI can display it instantly.

We also serve static assets from a public folder so the UI can be loaded from the same server. Keeping everything in one Express app simplifies local development and mirrors how PasteKit bundles its backend and frontend.

server.js

const express = require('express');
const bodyParser = require('body-parser');
const yaml = require('js-yaml');
const app = express();
let lastResult = '';
app.use(bodyParser.text({type: '*/*'}));
app.use(express.static('public'));
function isJson(str){
  try{JSON.parse(str);return true;}catch(e){return false;}
}
app.post('/format', (req,res)=>{
  const raw = req.body;
  let formatted;
  if(isJson(raw)){
    formatted = JSON.stringify(JSON.parse(raw),null,2);
  }else{
    const obj = yaml.load(raw);
    formatted = yaml.dump(obj, {indent:2});
  }
  lastResult = formatted;
  res.send(formatted);
});
app.get('/last', (req,res)=>res.send(lastResult));
app.listen(3000,()=>console.log('Listening on 3000'));
4

Phase 4: Minimal UI

The UI is a single HTML page that lets users paste raw JSON or YAML, hit a button, and see the pretty output. A <textarea> captures the input, a button triggers a fetch POST to /format, and a <pre> element displays the response.

All JavaScript lives inline for simplicity; it serializes the textarea value, sends it, and writes the server’s response back to the page. This minimal interface is enough to verify the core formatting logic works end‑to‑end.

public/index.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>PasteKit‑Style Formatter</title>
  <style>body{font-family:sans-serif;margin:2rem;}textarea{width:100%;height:150px;}</style>
</head>
<body>
  <h1>JSON/YAML Formatter</h1>
  <textarea id="input" placeholder="Paste JSON or YAML here"></textarea><br/>
  <button id="formatBtn">Format</button>
  <h2>Result</h2>
  <pre id="output"></pre>
  <script>
    document.getElementById('formatBtn').onclick=()=>{
      const txt=document.getElementById('input').value;
      fetch('/format',{method:'POST',body:txt})
        .then(r=>r.text())
        .then(data=>document.getElementById('output').textContent=data)
        .catch(err=>alert('Error: '+err));
    };
  </script>
</body>
</html>

Phase 5: Run & verify locally

Now start the server and open the UI in a browser. The Express app will listen on port 3000 and serve the static page from public/. Once the page loads, you can test formatting both JSON and YAML inputs.

If everything is wired correctly, the server logs “Listening on 3000”, the UI appears, and the formatted output shows up after clicking the button.

node server.js
