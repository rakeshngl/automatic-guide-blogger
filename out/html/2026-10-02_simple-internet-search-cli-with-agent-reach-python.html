Simple Internet Search CLI with Agent‑Reach (Python)

A beginner‑friendly clone that queries the web from the command line using free open‑source tools

Welcome to another official UVF IT build guide! In this tutorial we’ll create a minimal command‑line search tool inspired by Agent‑Reach, letting your Python script fetch web results without paying for proprietary APIs.

You’ll spin up a tiny FastAPI server that proxies requests to the free DuckDuckGo Instant Answer API, then call it from a local CLI – all in under 45 minutes.

Before you start…

  • You need Python 3.10+ and git installed; the guide assumes a Unix‑like shell.
  • The real Agent‑Reach bundles headless browsers and paid proxy services – our clone uses only DuckDuckGo’s public JSON endpoint, so results are less rich and may be rate‑limited.
  • Make sure port 8000 is free; the FastAPI server will bind to it.

Phase 2: Core feature – FastAPI proxy that calls DuckDuckGo

We expose a single /search endpoint that forwards the query to DuckDuckGo’s public JSON API and returns the top abstract. The endpoint accepts a q query‑parameter, contacts DuckDuckGo, extracts the first result, and sends it back as plain JSON.

FastAPI makes routing trivial and lets us keep the code readable for beginners. The server will run on http://127.0.0.1:8000 and be ready for the CLI to call.

app.py

from fastapi import FastAPI, HTTPException
import httpx

app = FastAPI()

DDG_ENDPOINT = "https://api.duckduckgo.com/"

@app.get("/search")
async def search(q: str):
    params = {"q": q, "format": "json", "no_redirect": 1, "no_html": 1}
    async with httpx.AsyncClient() as client:
        resp = await client.get(DDG_ENDPOINT, params=params, timeout=10)
    if resp.status_code != 200:
        raise HTTPException(status_code=502, detail="DuckDuckGo service unavailable")
    data = resp.json()
    # Return the first abstract if available, else a friendly message
    abstract = data.get("AbstractText") or "No concise answer found."
    return {"query": q, "answer": abstract}

Phase 3: CLI client to call the local API

In this step we create a tiny Python script that reads a search term from the command line and asks our local FastAPI server for results. The script uses httpx – a lightweight async‑friendly HTTP client – to keep the code simple and fast. When the server replies, we extract the human‑readable result field and print it so the user sees the answer directly in the terminal.

search_cli.py

import sys
import httpx

def main():
    if len(sys.argv) < 2:
        print('Usage: python search_cli.py <query>')
        sys.exit(1)
    query = ' '.join(sys.argv[1:])
    try:
        resp = httpx.get('http://127.0.0.1:8000/search', params={'q': query})
        resp.raise_for_status()
        data = resp.json()
        print(data.get('result', 'No result returned'))
    except Exception as e:
        print(f'Error contacting API: {e}')

if __name__ == '__main__':
    main()

Phase 5: Verify and extend

After confirming the plain text output, you can make the CLI richer by adding a --json flag that prints the full JSON payload. Using Python's built‑in argparse keeps the interface familiar and lets you easily add more options later, such as limiting results or switching endpoints. The extended version replaces the previous script but remains backward compatible – it still works without any flags.

The extra flag is useful for developers who want to see the raw data, integrate it into other tools, or debug the API response. Feel free to experiment with additional arguments as your project grows.

search_cli.py

import sys
import argparse
import httpx
import json

def query_api(q: str) -> dict:
    resp = httpx.get('http://127.0.0.1:8000/search', params={'q': q})
    resp.raise_for_status()
    return resp.json()

def main():
    parser = argparse.ArgumentParser(description='Simple internet search via local FastAPI')
    parser.add_argument('query', nargs='+', help='Search terms')
    parser.add_argument('--json', action='store_true', help='Print raw JSON response')
    args = parser.parse_args()
    q = ' '.join(args.query)
    try:
        data = query_api(q)
        if args.json:
            print(json.dumps(data, indent=2))
        else:
            print(data.get('result', 'No result returned'))
    except Exception as e:
        print(f'Error contacting API: {e}', file=sys.stderr)
        sys.exit(1)

if __name__ == '__main__':
    main()
