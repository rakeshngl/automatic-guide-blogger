Minimal Agentic Skill with Superpowers (Shell)

A 45‑minute clone using Python & SQLite

Welcome to another official UVF IT build guide. In this tutorial you’ll create a tiny “agentic skill” that can execute shell commands on demand, inspired by the Superpowers project’s shell skill.

We’ll use plain Python, the built‑in subprocess module and a tiny SQLite store to keep a history – all on your local machine, no paid APIs required.

Before you start

  • You need Python 3.9+ and sqlite3 (bundled with Python).
  • The clone only runs commands you type; it does not include any safety sandbox – never feed untrusted input.
  • Real Superpowers includes many more skills, a planning engine and LLM integration – this is just a minimal proof‑of‑concept.

Phase 2: Data model – SQLite history

A tiny SQLite file stores each command and its output for later inspection.

history.py

import sqlite3
import os
from datetime import datetime

DB_PATH = os.path.join(os.path.dirname(__file__), 'history.db')

def _init_db():
    """Create the history table if it doesn't exist."""
    conn = sqlite3.connect(DB_PATH)
    cur = conn.cursor()
    cur.execute('''
        CREATE TABLE IF NOT EXISTS command_history (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            timestamp TEXT NOT NULL,
            command TEXT NOT NULL,
            output TEXT NOT NULL
        )
    ''')
    conn.commit()
    conn.close()

def log_command(command: str, output: str):
    """Insert a command and its output into the DB.
    Args:
        command: The raw shell command string.
        output: The captured stdout+stderr from the command.
    """
    conn = sqlite3.connect(DB_PATH)
    cur = conn.cursor()
    cur.execute(
        'INSERT INTO command_history (timestamp, command, output) VALUES (?,?,?)',
        (datetime.utcnow().isoformat(), command, output)
    )
    conn.commit()
    conn.close()

# Initialise the DB on import so later modules can just call log_command
_init_db()

Phase 3: Core skill – execute shell & expose CLI

In this step we turn the scaffold into a usable command‑line tool. The script will accept a shell command, run it, store the command and its output in the SQLite database, and finally print the result so you can see it immediately. Keeping the logic tiny makes it easy to extend later with more agentic abilities, such as file manipulation or LLM‑driven suggestions.

We use Python's subprocess.run for safe execution, sqlite3 for persistence, and argparse to handle a simple --history flag. The database schema was created in Phase 2, so here we only insert new rows and query when the user asks for history.

agent.py

import argparse, subprocess, sqlite3, sys, os

DB_PATH = os.getenv('AGENT_DB', 'history.db')

def init_db():
    conn = sqlite3.connect(DB_PATH)
    conn.execute('''CREATE TABLE IF NOT EXISTS runs (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        command TEXT NOT NULL,
        output TEXT,
        timestamp DATETIME DEFAULT CURRENT_TIMESTAMP
    )''')
    conn.commit()
    return conn

def log_run(conn, cmd, out):
    conn.execute('INSERT INTO runs (command, output) VALUES (?, ?)', (cmd, out))
    conn.commit()

def show_history(conn, limit=10):
    cur = conn.execute('SELECT id, command, timestamp FROM runs ORDER BY id DESC LIMIT ?', (limit,))
    rows = cur.fetchall()
    if not rows:
        print('No history yet.')
        return
    for row in rows:
        print(f"{row[0]:>3}: [{row[2]}] {row[1]}")

def run_command(conn, cmd):
    try:
        result = subprocess.run(cmd, shell=True, capture_output=True, text=True, check=True)
        output = result.stdout.strip()
    except subprocess.CalledProcessError as e:
        output = e.stderr.strip() or str(e)
    print(output)
    log_run(conn, cmd, output)

def main():
    parser = argparse.ArgumentParser(description='Minimal agentic shell skill')
    parser.add_argument('command', nargs='*', help='Shell command to execute')
    parser.add_argument('--history', action='store_true', help='Show recent command history')
    args = parser.parse_args()

    conn = init_db()

    if args.history:
        show_history(conn)
        sys.exit(0)

    if not args.command:
        parser.print_help()
        sys.exit(1)

    cmd_str = ' '.join(args.command)
    run_command(conn, cmd_str)

if __name__ == '__main__':
    main()

Phase 4: Run locally

Now that the CLI is ready, activate the virtual environment you created earlier, and launch the script with a simple command. Try a harmless command like date to see the output and verify that the run is recorded in the SQLite file. You can also request the recent history to confirm the logging worked.

# Activate the virtual environment (adjust path if you used a different name)
source venv/bin/activate

# Run a demo command – this will print the current date and store it
python agent.py "date"

# Show the last few commands recorded in the database
python agent.py --history

Phase 5: Verify & extend

Check that the SQLite file exists, that the runs table contains at least one row, and that the CLI printed the command output. Once the core works, you can start adding new skills: for example, a file sub‑command that reads or writes files, or a wrapper that calls an LLM to generate commands automatically. The pattern stays the same – execute, log, and return results – so scaling up is straightforward.

# Verify the database was created and contains entries
ls -l history.db
sqlite3 history.db "SELECT id, command, output FROM runs ORDER BY id DESC LIMIT 5;"
