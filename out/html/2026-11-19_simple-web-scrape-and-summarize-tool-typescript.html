Simple Web‑Scrape‑and‑Summarize Tool (TypeScript)

A beginner‑friendly clone of Firecrawl’s core scrape‑and‑summarize flow using only free Node.js libraries

Welcome to another official UVU IT build guide! In the next 45 minutes you’ll create a tiny TypeScript app that fetches a web page, extracts its main text, and returns a short summary – a stripped‑down version of Firecrawl’s scrape‑and‑summarize endpoint.

We’ll stick to free‑tier tools: Node 20, node-fetch for HTTP, cheerio for DOM parsing, and a tiny heuristic summarizer. No paid APIs, no databases – just a single runnable script.

Before you start…

  • You need Node 20 (or later) installed; older versions lack native ES modules support used here.
  • The summarizer is a naïve sentence‑truncation – it won’t match Firecrawl’s AI‑powered output but demonstrates the pipeline.
  • Some sites block automated requests; if you get a 403, try a different URL or add a User‑Agent header.

Phase 2: Core – fetch and parse HTML

Create a tiny module that downloads a page and extracts visible text using Cheerio.

src/scraper.ts

import fetch from 'node-fetch';
import * as cheerio from 'cheerio';

/**
 * Download a web page and return its visible text.
 * We strip scripts, styles and hidden elements, then join the remaining text nodes.
 */
export async function scrape(url: string): Promise<string> {
  const response = await fetch(url, {
    headers: { 'User-Agent': 'UVF-IT-Clone/1.0' }
  });
  if (!response.ok) throw new Error(`Failed to fetch ${url}: ${response.status}`);
  const html = await response.text();
  const $ = cheerio.load(html);
  // Remove script/style/comments
  $('script, style, noscript').remove();
  // Get visible text
  const text = $('body')
    .find('*')
    .contents()
    .filter((_, el) => el.type === 'text')
    .map((_, el) => $(el).text().trim())
    .get()
    .filter(t => t.length > 0)
    .join(' ');
  return text;
}

Phase 3: Core – naive summarizer

In this step we add a tiny summarizer that simply grabs the first few sentences of the extracted text. It’s fast, requires no external services, and gives us a predictable output for testing. The function lives in its own module so we can swap it out later with an LLM or more sophisticated algorithm.

We’ll split the text on period‑space boundaries, trim empty pieces, and join the requested number of sentences back together. Keeping the implementation tiny also keeps the TypeScript compile time short, which is perfect for a beginner project.

src/summarizer.ts

export function summarize(text: string, sentenceCount: number = 3): string {
  if (!text) return '';
  // Split on period followed by a space or newline – simple sentence detection
  const rawSentences = text.split(/\.\s+|\.\n+/);
  const sentences = rawSentences.filter(s => s.trim().length > 0);
  const selected = sentences.slice(0, sentenceCount);
  // Re‑attach the period we stripped during split
  return selected.map(s => s.trim() + '.').join(' ');
}

Phase 4: Glue – CLI entry point

Now we wire everything together: the scraper (which fetches raw HTML and extracts readable text) and our new summarizer. The CLI driver parses a URL argument, runs the scrape‑then‑summarize pipeline, and prints a JSON blob to stdout – exactly what the Firecrawl API returns.

Using plain Node.js process.argv keeps dependencies minimal. All async work is wrapped in an immediately‑invoked async function so the script can be run with ts-node without extra boilerplate.

src/index.ts

import { scrape } from './scraper'; // assumed existing module
import { summarize } from './summarizer';

(async () => {
  const args = process.argv.slice(2);
  if (args.length === 0) {
    console.error('Usage: ts-node src/index.ts <URL>');
    process.exit(1);
  }
  const url = args[0];
  try {
    const rawText = await scrape(url); // returns plain text
    const summary = summarize(rawText);
    const output = { url, summary };
    console.log(JSON.stringify(output, null, 2));
  } catch (err) {
    console.error('Error:', err instanceof Error ? err.message : err);
    process.exit(1);
  }
})();
