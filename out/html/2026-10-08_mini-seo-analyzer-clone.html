Mini SEO Analyzer Clone

A lightweight Python SEO tool inspired by OpenSEO

Welcome to another official UVF IT guide where we roll up our sleeves and build a tiny SEO analyzer, echoing the spirit of OpenSEO’s open‑source Semrush alternative. In just ~45 minutes you’ll have a local Flask app that fetches page titles, meta descriptions, and word counts without any paid APIs.

We’ll use Python, Flask, and SQLite – all free tier – to mimic the core insight features of OpenSEO. The result is a runnable prototype you can extend into a full‑blown visibility dashboard.

Before you start

  • You need Python 3.9+ and git installed; older versions may break the virtual‑env setup.
  • The clone only extracts basic on‑page data (title, meta description, word count) – no backlink or keyword difficulty analysis like the full product.
  • Running on Windows may require python -m venv venv instead of python3 -m venv venv.

Phase 2: Define the SQLite model

We need a persistent store for each URL we analyze. A single SQLite table is enough for a minimal clone; it holds the URL, the page title, the meta description, and a simple word‑count metric. Using SQLAlchemy keeps the code database‑agnostic and easy to query later.

The model lives in app/models.py and will be imported by the route handlers when we save analysis results.

app/models.py

from flask_sqlalchemy import SQLAlchemy
from app import app

# configure SQLite database (file will be created automatically)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///seo_results.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

db = SQLAlchemy(app)

class PageAnalysis(db.Model):
    __tablename__ = 'page_analysis'
    id = db.Column(db.Integer, primary_key=True)
    url = db.Column(db.String(2083), unique=True, nullable=False)
    title = db.Column(db.String(255))
    description = db.Column(db.Text)
    word_count = db.Column(db.Integer)

    def __repr__(self):
        return f'<PageAnalysis {self.url}>'

# create tables if they don't exist yet
with app.app_context():
    db.create_all()

Phase 3: Build the scraper and API endpoint

In this step we create a Flask route that accepts a URL, fetches the page, and extracts the SEO basics we need. We'll pull the <title> tag, the meta description, and count the total number of words in the visible text. The result is stored in a tiny SQLite table so you can look at past analyses later. Keeping everything in one file makes the clone easy to understand and run.

app/routes.py

import sqlite3
from flask import Blueprint, request, jsonify, render_template
import requests
from bs4 import BeautifulSoup

bp = Blueprint('seo', __name__)

# Simple SQLite helper
DB_PATH = 'seo_results.db'

def init_db():
    conn = sqlite3.connect(DB_PATH)
    c = conn.cursor()
    c.execute('''CREATE TABLE IF NOT EXISTS results (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        url TEXT NOT NULL,
        title TEXT,
        description TEXT,
        word_count INTEGER,
        created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    )''')
    conn.commit()
    conn.close()

init_db()

def scrape(url):
    resp = requests.get(url, timeout=10)
    resp.raise_for_status()
    soup = BeautifulSoup(resp.text, 'html.parser')
    title = soup.title.string.strip() if soup.title else ''
    desc_tag = soup.find('meta', attrs={'name':'description'})
    description = desc_tag['content'].strip() if desc_tag and desc_tag.get('content') else ''
    # Get visible text and count words
    for script in soup(['script', 'style']):
        script.decompose()
    text = soup.get_text(separator=' ', strip=True)
    word_count = len(text.split())
    return title, description, word_count

@bp.route('/', methods=['GET'])
def index():
    return render_template('index.html')

@bp.route('/analyze', methods=['POST'])
def analyze():
    url = request.form.get('url')
    if not url:
        return jsonify({'error': 'URL is required'}), 400
    try:
        title, description, word_count = scrape(url)
    except Exception as e:
        return jsonify({'error': str(e)}), 500
    # Store result
    conn = sqlite3.connect(DB_PATH)
    c = conn.cursor()
    c.execute('INSERT INTO results (url, title, description, word_count) VALUES (?,?,?,?)',
              (url, title, description, word_count))
    conn.commit()
    conn.close()
    return jsonify({'url': url, 'title': title, 'description': description, 'word_count': word_count})

Phase 4: Run locally

Now we fire up the Flask development server and point our browser at the UI. The server will automatically reload when you edit the code, which is handy while you experiment. Make sure you have the virtual environment activated and Flask installed before you start.

export FLASK_APP=app
export FLASK_ENV=development
flask run

Phase 5: Verify and extend

With the server running, send a quick POST request to see the JSON payload with title, description, and word count. Open the root URL in a browser to use the simple HTML form we bundled in templates/index.html. Once the basics work, you can easily add features like CSV export or a tiny chart using Chart.js to visualize word count trends. Experiment and have fun extending the clone!

curl -X POST -d "url=https://example.com" http://127.0.0.1:5000/analyze
