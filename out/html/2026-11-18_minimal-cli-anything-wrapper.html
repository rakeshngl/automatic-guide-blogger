Minimal CLI‑Anything Wrapper

Run any shell command via a tiny AI‑agent style CLI

Welcome to another official UVF IT guide! In this quick build you’ll create a minimal clone of the CLI‑Anything concept – a tiny Python tool that lets an AI‑style agent invoke any system command and get back the result.

We’ll use only the Python standard library and SQLite for a tiny history log, so you can have a working prototype in about 45 minutes without any paid services.

Before you start

  • You need Python 3.9+ installed and git for cloning the repo (optional).
  • The clone only executes plain shell commands – no sandboxing, so avoid running untrusted input.
  • It stores a tiny command history in a local SQLite file, unlike the full CLI‑Anything hub which supports plugins and remote packages.

Phase 2: Data model – SQLite history log

We need a lightweight way to remember every command the agent runs and its output. SQLite, bundled with Python, is perfect – no external server, just a file on disk.

The following script creates a history table with columns for an auto‑incrementing ID, the raw command string, its stdout, stderr, and a timestamp. Running it once sets up the database for the rest of the project.

init_db.py

import sqlite3
import datetime

DB_PATH = "history.db"

def init_db() -> None:
    conn = sqlite3.connect(DB_PATH)
    cur = conn.cursor()
    cur.execute(
        """
        CREATE TABLE IF NOT EXISTS history (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            command TEXT NOT NULL,
            stdout TEXT,
            stderr TEXT,
            executed_at TEXT NOT NULL
        );
        """
    )
    conn.commit()
    conn.close()
    print(f"Initialized SQLite history at {DB_PATH}")

if __name__ == "__main__":
    init_db()

Phase 3: Core feature – execute arbitrary command

The core of the clone is a tiny Python script that accepts a single command‑line argument, runs it, and captures both standard output and error streams. We store each invocation in a local SQLite database so you can later review what was executed and what it returned. This mirrors the original CLI‑Anything behavior while keeping the implementation minimal.

We use the built‑in subprocess module for safe execution and sqlite3 for persistence. The script creates the database on first run, inserts a record for every call, and finally prints the captured output so the user sees the result immediately.

cli_anything_clone.py

#!/usr/bin/env python3
import sys, sqlite3, subprocess, datetime, os
DB_PATH = os.path.join(os.path.dirname(__file__), 'history.db')

def init_db():
    conn = sqlite3.connect(DB_PATH)
    cur = conn.cursor()
    cur.execute('''CREATE TABLE IF NOT EXISTS runs (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        timestamp TEXT,
        command TEXT,
        stdout TEXT,
        stderr TEXT
    )''')
    conn.commit()
    conn.close()

def log_run(command, out, err):
    conn = sqlite3.connect(DB_PATH)
    cur = conn.cursor()
    cur.execute('INSERT INTO runs (timestamp, command, stdout, stderr) VALUES (?,?,?,?,?)',
                (datetime.datetime.utcnow().isoformat(), command, out, err))
    conn.commit()
    conn.close()

def main():
    if len(sys.argv) < 2:
        print('Usage: cli_anything_clone.py "<command>"')
        sys.exit(1)
    cmd = ' '.join(sys.argv[1:])
    # Execute the command, capture output
    result = subprocess.run(cmd, shell=True, capture_output=True, text=True)
    stdout = result.stdout.strip()
    stderr = result.stderr.strip()
    # Log to SQLite
    log_run(cmd, stdout, stderr)
    # Show result to user
    if stdout:
        print(stdout)
    if stderr:
        print(stderr, file=sys.stderr)

if __name__ == '__main__':
    init_db()
    main()

Phase 4: Run locally

Now that the script is ready, initialize the database once (the script does this automatically on first execution) and try a simple command. The demo below runs an echo statement, which will be captured, stored, and displayed.

You can replace the example with any shell command – the wrapper treats it as a black box, just like the original CLI‑Anything tool.

# Make the script executable
chmod +x cli_anything_clone.py

# Run a demo command
./cli_anything_clone.py "echo Hello from AI"

Phase 5: Verify & extend

After the demo, inspect the SQLite file to confirm that the command and its output were recorded. You can query the runs table with the sqlite3 CLI or any SQLite viewer.

Future extensions are easy: add a --json flag to emit the result as JSON, or wrap the script in a tiny Flask endpoint to expose it over HTTP for remote agents.

# View the history database (SQLite CLI)
sqlite3 history.db "SELECT id, timestamp, command, stdout FROM runs ORDER BY id DESC LIMIT 5;"
