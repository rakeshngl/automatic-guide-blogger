CLI‑Anything Minimal Clone

Turn any shell command into an AI‑friendly HTTP endpoint

Welcome to another official UVF IT guide. In this quick‑fire tutorial you’ll build a tiny web service that lets an AI agent (or any client) invoke arbitrary shell commands over HTTP – the core idea behind CLI‑Anything.

We’ll use Flask (free, open‑source) and the built‑in subprocess module, so you can have a working prototype in about 45 minutes without any paid APIs.

Before you start…

  • You need Python 3.10 or newer and pip installed on your machine.
  • Running arbitrary commands is dangerous – this clone runs them without sandboxing; never expose it to the public internet.
  • The real CLI‑Anything project adds schema validation, authentication, and a community hub – we skip those for brevity.

Phase 2: Core model – safe command runner

Wrap subprocess.run in a helper that captures stdout, stderr and limits execution time.

runner.py

import subprocess, shlex, threading

class CommandTimeout(Exception):
    pass

def _run_with_timeout(cmd, timeout):
    """Execute *cmd* safely, returning stdout, stderr.
    Raises CommandTimeout if the process exceeds *timeout* seconds.
    """
    # Split string safely; callers can also pass a list.
    args = shlex.split(cmd) if isinstance(cmd, str) else cmd
    proc = subprocess.Popen(args, stdout=subprocess.PIPE, stderr=subprocess.PIPE, text=True)
    timer = threading.Timer(timeout, proc.kill)
    try:
        timer.start()
        out, err = proc.communicate()
        if proc.returncode != 0:
            raise subprocess.CalledProcessError(proc.returncode, cmd, out, err)
        return out, err
    finally:
        timer.cancel()
        if proc.poll() is None:
            raise CommandTimeout(f"Command '{cmd}' timed out after {timeout}s")

def run_command(command, timeout=5):
    """Public helper used by the Flask endpoint.
    Returns a dict with *stdout*, *stderr* and *error* fields.
    """
    try:
        stdout, stderr = _run_with_timeout(command, timeout)
        return {"stdout": stdout, "stderr": stderr, "error": None}
    except subprocess.CalledProcessError as e:
        return {"stdout": e.output, "stderr": e.stderr, "error": f"Non‑zero exit: {e.returncode}"}
    except CommandTimeout as e:
        return {"stdout": "", "stderr": "", "error": str(e)}

Phase 3: API layer – expose `/run` endpoint

In this step we add a tiny Flask API that listens for POST requests on /run. The request body must contain a JSON object with a cmd key holding the shell command you want to run. The server will execute the command, capture stdout and stderr, and return them as JSON so any client – including an LLM – can consume the result easily.

app.py

from flask import Flask, request, jsonify
import subprocess

app = Flask(__name__)

@app.route('/run', methods=['POST'])
def run_cmd():
    data = request.get_json(silent=True) or {}
    cmd = data.get('cmd')
    if not cmd:
        return jsonify({'error': 'No cmd provided'}), 400
    try:
        completed = subprocess.run(cmd, shell=True, capture_output=True, text=True, timeout=10)
        return jsonify({
            'out': completed.stdout,
            'err': completed.stderr,
            'returncode': completed.returncode
        })
    except Exception as e:
        return jsonify({'error': str(e)}), 500

if __name__ == '__main__':
    app.run(debug=True)

Phase 4: Run locally and test

Now we fire up the Flask server and send a simple request to verify everything works. Running the app in the background lets you keep using the same terminal for testing. A curl command posts a JSON payload and prints the formatted response, showing the command output under the out field.

# Start the server (press Ctrl+C to stop later)
python app.py &
SERVER_PID=$!
# Give Flask a moment to start
sleep 1
# Test the endpoint with a harmless command
curl -s -X POST http://127.0.0.1:5000/run \
     -H 'Content-Type: application/json' \
     -d '{"cmd":"echo hello world"}' | python -m json.tool
# Clean up the background server
kill $SERVER_PID

Phase 5: Optional – simple token auth

To avoid exposing the endpoint to anyone on the network, we add a static token check. The server expects an X-Token header with a secret value; if the header is missing or incorrect, the request is rejected with a 403 status. This lightweight guard is enough for a local demo and can be swapped for a full auth system later.

app.py

from flask import Flask, request, jsonify
import subprocess

app = Flask(__name__)

# Simple shared secret – change it before you go public
SECRET_TOKEN = 'secret'

@app.before_request
def check_token():
    token = request.headers.get('X-Token')
    if token != SECRET_TOKEN:
        return jsonify({'error': 'Invalid or missing token'}), 403

@app.route('/run', methods=['POST'])
def run_cmd():
    data = request.get_json(silent=True) or {}
    cmd = data.get('cmd')
    if not cmd:
        return jsonify({'error': 'No cmd provided'}), 400
    try:
        completed = subprocess.run(cmd, shell=True, capture_output=True, text=True, timeout=10)
        return jsonify({
            'out': completed.stdout,
            'err': completed.stderr,
            'returncode': completed.returncode
        })
    except Exception as e:
        return jsonify({'error': str(e)}), 500

if __name__ == '__main__':
    app.run(debug=True)
