Simple Self‑Hosted Monitoring Dashboard (Node.js + SQLite)

A minimal clone of Uptime‑Kuma for beginners

Welcome to another official UVF IT build guide! In this tutorial we’ll create a tiny monitoring dashboard inspired by Uptime‑Kuma, using only Node.js, Express, and SQLite – all free on your local machine.

You’ll have a working web UI that lets you add a URL, stores it in SQLite, and pings it every 30 seconds, displaying “UP” or “DOWN”. All in ~45 minutes!

Before you start

  • Node.js >= 18 and npm must be installed – older versions may lack native fetch support.
  • The clone only supports HTTP(s) GET checks; advanced probes (TCP, DNS, notifications) are omitted for simplicity.
  • SQLite file is created in the project folder; ensure you have write permission.

Phase 2: Data model (SQLite)

Now we add persistence. A single SQLite table called monitors will hold each URL we want to watch, the last known HTTP status, and a timestamp of the last check. Using better‑sqlite3 means we can run synchronous queries during startup without callbacks, keeping the code easy to read for beginners.

src/db.js

const Database = require('better-sqlite3');
const path = require('path');
// SQLite file lives next to package.json
const dbPath = path.resolve(__dirname, '../monitor.db');
const db = new Database(dbPath);
// Create table if it doesn't exist
const createStmt = `
CREATE TABLE IF NOT EXISTS monitors (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  url TEXT NOT NULL,
  last_status TEXT,
  last_checked INTEGER
);
`;
db.exec(createStmt);
// Helper functions
function addMonitor(url) {
  const stmt = db.prepare('INSERT INTO monitors (url) VALUES (?)');
  return stmt.run(url);
}
function getAllMonitors() {
  return db.prepare('SELECT * FROM monitors').all();
}
module.exports = {addMonitor, getAllMonitors, db};
3

Phase 3: Core API & UI logic

In this phase we wire up a tiny Express server that talks to a SQLite database. The server will expose three REST endpoints: one to list all monitored sites, one to add a new site, and one to fetch the latest status of a site. We also serve a minimal HTML page that polls the list endpoint every few seconds so you can see live status updates.

The code below creates the database schema if it doesn't exist, defines the routes, and serves static files from a 'public' folder. Keeping everything in one file makes the clone easy to understand and modify for beginners.

server.js

const express = require('express');
const sqlite3 = require('sqlite3').verbose();
const path = require('path');
const fetch = require('node-fetch');

const app = express();
const DB_FILE = 'data.db';
const db = new sqlite3.Database(DB_FILE);

// Initialise DB
db.serialize(() => {
  db.run(`CREATE TABLE IF NOT EXISTS sites (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    url TEXT NOT NULL,
    status TEXT DEFAULT 'UNKNOWN',
    last_check INTEGER`
  );`);
});

app.use(express.json());
app.use(express.static(path.join(__dirname, 'public')));

// Helper to ping a site
async function pingSite(url) {
  try {
    const res = await fetch(url, { method: 'GET', timeout: 5000 });
    return res.ok ? 'UP' : 'DOWN';
  } catch (_) { return 'DOWN'; }
}

// List all sites
app.get('/api/sites', (req, res) => {
  db.all('SELECT * FROM sites', [], (err, rows) => {
    if (err) return res.status(500).json({error: err.message});
    res.json(rows);
  });
});

// Add a new site
app.post('/api/sites', async (req, res) => {
  const {url} = req.body;
  if (!url) return res.status(400).json({error: 'url required'});
  const status = await pingSite(url);
  const now = Date.now();
  db.run('INSERT INTO sites (url, status, last_check) VALUES (?,?,?)', [url, status, now], function(err) {
    if (err) return res.status(500).json({error: err.message});
    res.json({id: this.lastID, url, status, last_check: now});
  });
});

// Get status of a single site (optional)
app.get('/api/sites/:id', (req, res) => {
  db.get('SELECT * FROM sites WHERE id = ?', [req.params.id], (err, row) => {
    if (err) return res.status(500).json({error: err.message});
    if (!row) return res.status(404).json({error: 'Not found'});
    res.json(row);
  });
});

// Simple background pinger (runs every 30s)
setInterval(() => {
  db.all('SELECT id, url FROM sites', [], async (err, rows) => {
    if (err) return console.error(err);
    for (const {id, url} of rows) {
      const status = await pingSite(url);
      db.run('UPDATE sites SET status = ?, last_check = ? WHERE id = ?', [status, Date.now(), id]);
    }
  });
}, 30000);

const PORT = 3000;
app.listen(PORT, () => console.log(`🚀 http://localhost:${PORT}`));

Phase 4: Run locally

Now that the server code and a tiny front‑end live in the repository, you just need to install dependencies and start the app. The command installs Express, SQLite3, and node‑fetch, then launches the server. Once running, open your browser to the printed address to see the dashboard UI.

npm init -y
npm install express sqlite3 node-fetch
node server.js

Phase 5: Verify & extend

With the server up, you can add a site using curl or the UI form. After a short moment the background pinger updates the status, which the UI reflects automatically because it polls the list endpoint every few seconds. As a next step, try adding a simple webhook notification: when a site goes DOWN, POST a JSON payload to a URL you control.

curl -X POST http://localhost:3000/api/sites -H "Content-Type: application/json" -d '{"url":"https://example.com"}'
