Multi‑Source Topic Summarizer Skill (Claude‑style)

A minimal Python clone that fetches recent posts from Reddit and Hacker News, then summarizes with a local LLM

Welcome to another official UVF IT guide! In the next 45 minutes you’ll build a tiny “last‑30‑days” skill that pulls data from two public sources and runs a local summarizer – a stripped‑down version of the popular Claude plugin.

We’ll use plain Python, SQLite for caching, and the free ollama docker image for LLM inference, so no paid APIs are required.

Before you start…

  • Python 3.10+ and Docker must be installed; the guide uses the ollama/llama2 model which runs locally.
  • The real skill supports dozens of platforms and OAuth flows – our clone only handles Reddit’s public JSON endpoint and the Hacker News API.
  • Network hiccups can cause empty results; rerun the script if you see “No items fetched”.

Phase 2: Data model & caching

We need a place to remember which items we already fetched so we don’t hammer the APIs on every run. A tiny SQLite file works perfectly for a prototype. Here we define a table with columns for the source (reddit or hn), the item ID, title, URL, and the timestamp when we stored it. A small helper class wraps the connection and provides add_item and get_recent methods used later by the fetcher.

The helper also creates the table on first run, so you can delete the cache.db file to start fresh without any extra steps.

db.py

import sqlite3
from datetime import datetime, timedelta

class CacheDB:
    def __init__(self, path='cache.db'):
        self.conn = sqlite3.connect(path)
        self._ensure_schema()

    def _ensure_schema(self):
        cur = self.conn.cursor()
        cur.execute('''
            CREATE TABLE IF NOT EXISTS items (
                source TEXT NOT NULL,
                item_id TEXT NOT NULL,
                title TEXT,
                url TEXT,
                fetched_at TEXT NOT NULL,
                PRIMARY KEY (source, item_id)
            )
        ''')
        self.conn.commit()

    def add_item(self, source, item_id, title, url):
        cur = self.conn.cursor()
        cur.execute(
            'INSERT OR REPLACE INTO items (source, item_id, title, url, fetched_at) VALUES (?,?,?,?,?)',
            (source, item_id, title, url, datetime.utcnow().isoformat())
        )
        self.conn.commit()

    def get_recent(self, days=30):
        cutoff = datetime.utcnow() - timedelta(days=days)
        cur = self.conn.cursor()
        cur.execute(
            'SELECT source, item_id, title, url FROM items WHERE fetched_at > ?',
            (cutoff.isoformat(),)
        )
        return cur.fetchall()

Phase 3: Fetch from Reddit & Hacker News

In this step we reach out to two public APIs – Reddit’s JSON endpoint for the r/all hot posts and Hacker News’s Algolia search API – to collect the titles of the most popular submissions from the last 30 days. We filter out any posts that are stickied or lack a title, then store the cleaned results in a tiny SQLite cache so subsequent runs are fast and deterministic. The SQLite file (cache.db) will have a single table posts with columns for source, id, title, and fetched timestamp. This prepares the raw material for our summarizer without pulling duplicate data on every execution.

fetch.py

import sqlite3, time, requests, json

DB = 'cache.db'

def init_db():
    conn = sqlite3.connect(DB)
    cur = conn.cursor()
    cur.execute('''CREATE TABLE IF NOT EXISTS posts (
        source TEXT,
        post_id TEXT PRIMARY KEY,
        title TEXT,
        fetched_at INTEGER)''')
    conn.commit()
    conn.close()

def upsert(source, post_id, title):
    conn = sqlite3.connect(DB)
    cur = conn.cursor()
    cur.execute('INSERT OR REPLACE INTO posts (source, post_id, title, fetched_at) VALUES (?,?,?,?)',
                (source, post_id, title, int(time.time())))
    conn.commit()
    conn.close()

def fetch_reddit():
    url = 'https://www.reddit.com/r/all/top.json?t=month&limit=50'
    headers = {'User-Agent': 'uvf-it-summarizer/0.1'}
    resp = requests.get(url, headers=headers)
    data = resp.json()
    for item in data['data']['children']:
        post = item['data']
        if post.get('stickied'): continue
        upsert('reddit', post['id'], post['title'])

def fetch_hn():
    url = 'https://hn.algolia.com/api/v1/search_by_date?tags=story&numericFilters=created_at_i>$(date -d "30 days ago" +%s)'
    resp = requests.get(url)
    for hit in resp.json().get('hits', []):
        upsert('hackernews', str(hit['objectID']), hit['title'])

if __name__ == '__main__':
    init_db()
    fetch_reddit()
    fetch_hn()
    print('Fetch complete, stored posts in', DB)

Phase 4: Summarize with local LLM

Now that we have a collection of titles, we feed them to a local LLM running via Ollama. The script reads the SQLite cache, concatenates the titles into a prompt, and asks the Llama2 model to produce a concise three‑bullet summary of the overall trends. The output is printed to the console, ready for downstream use or display in a UI.

summarize.py

import sqlite3, subprocess, textwrap

DB = 'cache.db'

def load_titles():
    conn = sqlite3.connect(DB)
    cur = conn.cursor()
    cur.execute('SELECT source, title FROM posts')
    rows = cur.fetchall()
    conn.close()
    return rows

def build_prompt(titles):
    grouped = {'reddit': [], 'hackernews': []}
    for src, title in titles:
        grouped[src].append(title)
    prompt = "You are summarizing tech news. Provide a three‑bullet summary of the main trends from the following titles.\n\n"
    for src, list_ in grouped.items():
        prompt += f"{src.upper()} ({len(list_)} items):\n"
        for t in list_[:5]:
            prompt += f"- {t}\n"
        prompt += "\n"
    return prompt

def call_ollama(prompt):
    # Ollama expects JSON with model and prompt; we use subprocess to pipe stdin
    result = subprocess.run(
        ['ollama', 'run', 'llama2'],
        input=prompt.encode('utf-8'),
        capture_output=True,
        timeout=60
    )
    return result.stdout.decode('utf-8')

if __name__ == '__main__':
    titles = load_titles()
    if not titles:
        print('No posts found, run fetch.py first.')
        exit(1)
    prompt = build_prompt(titles)
    summary = call_ollama(prompt)
    print('--- Summary ---')
    print(textwrap.dedent(summary).strip())
