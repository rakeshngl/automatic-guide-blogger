Agent‑Skills‑inspired CLI Coding Assistant

A minimal Node.js CLI that mimics the slash‑command workflow of Agent Skills

Welcome to another official UVF IT guide. In the next 45 minutes you’ll spin up a tiny JavaScript CLI that understands slash‑style commands like /spec, /plan, and /build – a stripped‑down clone of Addy Osmani’s Agent Skills.

We’ll use plain Node.js (v18+), the built‑in readline module and a local SQLite database (via better-sqlite3) – all free, no external APIs. By the end you’ll have a working prototype you can extend with real AI or CI tools.

Before you start

  • Node 18+ and npm must be installed; older versions lack native ES‑modules support.
  • The clone stores data locally in SQLite – it does not integrate with GitHub, CI or real LLMs, so many advanced checks are simplified.
  • Running the CLI twice without resetting the DB will retain previous tasks; delete assistant.db to start fresh.

Phase 1: Scaffold the project

Create a fresh folder for the assistant, initialise it as an npm package, and pull in the SQLite driver we’ll use for persistence. This gives us a clean workspace and the only external dependency we need right now.

All commands are run from your terminal; once they finish you’ll have a package.json and a node_modules folder ready for the next step.

npm init -y
npm install better-sqlite3
2

Phase 2: Initialise SQLite and define the task model

We now create a tiny module that opens (or creates) a local SQLite file called assistant.db. It ensures a tasks table exists and exports helper functions to add a new task and fetch all tasks. Keeping this logic separate makes the CLI code tidy and testable.

db.js

import Database from 'better-sqlite3';

// Open (or create) the SQLite file in the project root
const db = new Database('assistant.db');

// Ensure the tasks table exists
const init = `CREATE TABLE IF NOT EXISTS tasks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  command TEXT NOT NULL,
  payload TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);`;
db.exec(init);

export function addTask(command, payload = null) {
  const stmt = db.prepare('INSERT INTO tasks (command, payload) VALUES (?, ?)');
  const info = stmt.run(command, payload);
  return info.lastInsertRowid;
}

export function getAllTasks() {
  const stmt = db.prepare('SELECT * FROM tasks ORDER BY created_at DESC');
  return stmt.all();
}

export default { addTask, getAllTasks };
3

Phase 3: Command dispatcher & simple handlers

In this step we create a tiny command router that maps slash‑style commands to functions. Each handler will log what it received and push a simple record into an in‑memory task list so we can verify later that the command was processed.

Keeping the logic isolated in its own file makes the CLI core clean and lets you swap out real implementations without touching the loop code.

commands.js

// commands.js – tiny dispatcher for slash commands
// A shared in‑memory store for demo purposes
const tasks = [];

// Helper to record a task
function recordTask(command, args) {
  const task = { id: tasks.length + 1, command, args, timestamp: new Date() };
  tasks.push(task);
  console.log(`✅ Recorded task #${task.id}: ${command}`);
}

// Handlers for each supported slash command
function handleSpec(args) { console.log('🔧 Spec received:', args.join(' ')); recordTask('/spec', args); }
function handlePlan(args) { console.log('🗺️ Plan received:', args.join(' ')); recordTask('/plan', args); }
function handleBuild(args) { console.log('🏗️ Build received:', args.join(' ')); recordTask('/build', args); }
function handleTest(args) { console.log('✅ Test received:', args.join(' ')); recordTask('/test', args); }
function handleReview(args) { console.log('🔍 Review received:', args.join(' ')); recordTask('/review', args); }

// Dispatcher maps command strings to handler functions
function dispatch(input) {
  const parts = input.trim().split(/\s+/);
  const cmd = parts[0];
  const args = parts.slice(1);
  switch (cmd) {
    case '/spec':   handleSpec(args); break;
    case '/plan':   handlePlan(args); break;
    case '/build':  handleBuild(args); break;
    case '/test':   handleTest(args); break;
    case '/review': handleReview(args); break;
    default:
      console.log(`❓ Unknown command: ${cmd}`);
  }
}

// Export both dispatcher and the task list for later inspection
module.exports = { dispatch, tasks };

Phase 4: Interactive CLI loop

Now we wire up Node's readline module to present a friendly agent> prompt. Every line the user types is sent to our dispatcher, and the loop continues until the user types exit or hits Ctrl‑C.

At the end we print a summary table of all recorded tasks so you can see that the commands were stored correctly.

index.js

// index.js – interactive CLI entry point
const readline = require('readline');
const { dispatch, tasks } = require('./commands');

const rl = readline.createInterface({
  input: process.stdin,
  output: process.stdout,
  prompt: 'agent> '
});

console.log('🤖 Welcome to the Agent‑Skills‑inspired CLI');
rl.prompt();

rl.on('line', (line) => {
  const trimmed = line.trim();
  if (trimmed === '' ) { rl.prompt(); return; }
  if (trimmed.toLowerCase() === 'exit') {
    rl.close();
    return;
  }
  dispatch(trimmed);
  rl.prompt();
}).on('close', () => {
  console.log('\n📋 Recorded tasks:');
  console.table(tasks);
  console.log('👋 Bye!');
  process.exit(0);
});
