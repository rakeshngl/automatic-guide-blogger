Build a CALL‑E‑style AI Phone Bot with Twilio and OpenAI

The phone line for AI agents – a minimal clone using free‑tier Twilio and OpenAI APIs

Welcome to another official UVF IT guide! In this quick‑fire tutorial we’ll spin up a tiny AI phone bot that answers calls, transcribes speech, and replies with GPT‑4‑generated text – all using Twilio’s free trial and OpenAI’s free‑tier model.

You’ll finish with a working webhook that you can call from your Twilio phone number. The stack is pure Python, SQLite for logging, and no paid services beyond the free trial limits.

Before you start…

  • You need Python 3.9+ and pip. Install the Twilio CLI (twilio) to expose a local webhook (or use ngrok).
  • The real CALL‑E product includes voice‑synthesis, multi‑agent routing, and a UI dashboard – we’ll skip those for brevity.
  • Twilio free trial only works with verified caller IDs; you won’t be able to call arbitrary numbers until you upgrade.
Minimal CALL‑E Clone Architecture
1

Phase 1: Scaffold the Flask project

Create a virtual environment so our dependencies stay isolated from any system packages. Then install Flask, the Twilio helper library, and SQLite support – all of which are tiny and free.

Add a tiny SQLite database file that will hold call logs. We keep it simple: a single table with columns for the call SID, timestamp, and raw transcription. No migrations needed for this prototype.

# Create project folder and navigate into it
mkdir call_e_clone && cd call_e_clone

# Set up a virtual environment
python3 -m venv venv
source venv/bin/activate

# Install required Python packages
pip install Flask twilio sqlite3

# Initialise an empty SQLite DB with a simple table
sqlite3 call_logs.db "CREATE TABLE IF NOT EXISTS calls (sid TEXT PRIMARY KEY, received_at TEXT, transcript TEXT);"
2

Phase 2: Receive a call and record speech

Twilio will POST to the /voice endpoint whenever someone dials your number. We answer the call, prompt the caller to speak, and tell Twilio to record the utterance. The recorded audio URL will be sent back to us on a later webhook (not covered yet).

app.py

from flask import Flask, request, Response
from twilio.twiml.voice_response import VoiceResponse
import sqlite3, datetime

app = Flask(__name__)
DB_PATH = 'call_logs.db'

def log_call(sid, transcript=None):
    conn = sqlite3.connect(DB_PATH)
    cur = conn.cursor()
    cur.execute(
        "INSERT OR REPLACE INTO calls (sid, received_at, transcript) VALUES (?, ?, ?)",
        (sid, datetime.datetime.utcnow().isoformat(), transcript)
    )
    conn.commit()
    conn.close()

@app.route('/voice', methods=['POST'])
def voice():
    call_sid = request.form.get('CallSid')
    # Log the incoming call immediately
    log_call(call_sid)
    resp = VoiceResponse()
    resp.say('Hello, you are connected to the AI phone bot. Please speak after the beep.')
    # Record the caller's speech; Twilio will POST the recording URL to /recording later
    resp.record(action='/recording', method='POST', maxLength=30, playBeep=True)
    resp.hangup()
    return Response(str(resp), mimetype='application/xml')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)

Phase 3: Get transcription and call OpenAI

When Twilio finishes recording your voice it sends a webhook that contains a URL to the audio file. We download that file, ask OpenAI’s Whisper model to turn it into plain text, then feed the text to GPT‑3.5‑Turbo for a response. Both the user’s transcript and the AI reply are saved in a tiny SQLite database so you can review the conversation later. Finally we tell Twilio to read the reply back to the caller using the <Say> verb, keeping the whole loop inside the same HTTP request.

app.py

import os, requests, sqlite3
from flask import Flask, request, Response
from twilio.twiml.voice_response import VoiceResponse
import openai

app = Flask(__name__)

# Initialise SQLite (creates file if missing)
DB_PATH = 'calls.db'
conn = sqlite3.connect(DB_PATH, check_same_thread=False)
conn.execute('''CREATE TABLE IF NOT EXISTS logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    from_number TEXT,
    transcript TEXT,
    reply TEXT,
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP
)''')
conn.commit()

# Load secrets from environment (set them in .env or export)
openai.api_key = os.getenv('OPENAI_API_KEY')

@app.route('/transcribe', methods=['POST'])
def transcribe():
    # Twilio sends many params; we need the RecordingUrl
    recording_url = request.form.get('RecordingUrl')
    from_number = request.form.get('From')
    if not recording_url:
        return str(VoiceResponse().say('Sorry, I could not find your recording.'))

    # 1️⃣ Fetch audio bytes
    audio_resp = requests.get(recording_url)
    audio_bytes = audio_resp.content

    # 2️⃣ Whisper transcription (audio must be sent as file)
    transcript_resp = openai.Audio.transcribe(
        model='whisper-1',
        file=('audio.wav', audio_bytes),
        response_format='text'
    )
    transcript = transcript_resp.strip()

    # 3️⃣ GPT reply
    gpt_resp = openai.ChatCompletion.create(
        model='gpt-3.5-turbo',
        messages=[{'role': 'user', 'content': transcript}]
    )
    reply = gpt_resp.choices[0].message.content.strip()

    # 4️⃣ Store in SQLite
    conn.execute(
        'INSERT INTO logs (from_number, transcript, reply) VALUES (?,?,?)',
        (from_number, transcript, reply)
    )
    conn.commit()

    # 5️⃣ Respond to Twilio – read the reply aloud
    resp = VoiceResponse()
    resp.say(reply, voice='alice')
    return Response(str(resp), mimetype='application/xml')

if __name__ == '__main__':
    # Flask's built‑in server is fine for a prototype
    app.run(host='0.0.0.0', port=5000)

Phase 4: Expose the webhook and link Twilio number

Your Flask app runs on localhost, but Twilio needs a publicly reachable URL to call back. Ngrok creates a secure tunnel that forwards a random internet address to your local port 5000. Once the tunnel is up, copy the HTTPS URL and tell your Twilio trial number to use the /transcribe endpoint for incoming voice calls.

# Install ngrok if you haven't already
brew install ngrok   # macOS; use apt-get or choco on other OSes

# Start a tunnel to port 5000 (Flask default)
ngrok http 5000

# The command prints something like:
# Forwarding https://abcd1234.ngrok.io -> http://localhost:5000
# Copy the HTTPS URL (e.g., https://abcd1234.ngrok.io)

# Then, in the Twilio Console → Phone Numbers → Manage → Active Numbers:
#   • Set "A CALL COMES IN" webhook URL to https://abcd1234.ngrok.io/transcribe
#   • Choose HTTP POST
# Save the changes.
5

Phase 5: Verify and extend

Give your Twilio number a ring, speak a short sentence, and listen for the AI’s answer. After the call ends, open a terminal and run the inspection command – it will print every row stored in the SQLite log, showing the caller, what they said, and what GPT replied. From here you can experiment: replace <Say> with Twilio’s <Play> of a custom TTS file, add multiple agents by passing a system prompt, or build a tiny web dashboard that reads the logs.

# Quick way to see the stored conversation logs
sqlite3 calls.db "SELECT id, from_number, transcript, reply, timestamp FROM logs ORDER BY id DESC LIMIT 5;"
