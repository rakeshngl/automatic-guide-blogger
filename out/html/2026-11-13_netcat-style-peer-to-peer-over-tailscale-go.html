Netcat‑style Peer‑to‑Peer over Tailscale (Go)

A minimal Tailcat‑inspired clone for beginners

Welcome to another official UVF IT build guide. In the next 45 minutes you’ll craft a tiny Go program that mimics Tailcat’s core: a listener that prints a short address and a client that connects using that address, all over Tailscale’s magicsock data‑plane.

We’ll rely only on the free, open‑source tailscale.com/magicsock package and a public DERP relay – no paid APIs, no root access, just Go and your terminal.

Before you start…

  • You need Go 1.22+ installed and $GOPATH/bin on your PATH.
  • The clone skips Tailcat’s address encoding and authentication – it only demonstrates encrypted UDP tunnels.
Component Overview
1

Phase 1: Scaffold the Go module

First we create a fresh directory for our project and tell Go to start a new module. This gives us a go.mod file that tracks our dependencies. Then we pull in the magicsock package, which handles the encrypted UDP transport over Tailscale’s DERP network. All of this is done with a few simple shell commands.

Running these commands will also download the required Go source files into your module cache, so later steps compile instantly.

mkdir tailcat-clone && cd tailcat-clone
go mod init tailcat-clone
go get tailscale.com/magicsock@latest
2

Phase 2: Implement the server (listener)

The server creates a magicsock Listener bound to a random UDP port. Magicsock automatically registers the socket with the public DERP relay, so any client that knows the printed address can reach us without opening firewall ports. After listening, we simply print host:port so the client can copy‑paste it.

Because we only need a minimal demo, we ignore Tailcat’s address‑encoding scheme and just output the raw address string. The code is self‑contained and compiles to a single binary.

server.go

package main

import (
    "fmt"
    "log"
    "net"
    "tailscale.com/magicsock"
)

func main() {
    // Create a magicsock listener on a random UDP port.
    l, err := magicsock.Listen("udp", "0.0.0.0:0")
    if err != nil {
        log.Fatalf("listen error: %v", err)
    }
    defer l.Close()

    // Resolve the actual address (host:port) that magicsock is using.
    addr := l.Addr().String()
    fmt.Printf("Server listening on %s\n", addr)

    // Block forever; a real program would accept connections here.
    select {}
}
3

Phase 3: Implement the client (connector)

In this step we write a tiny Go program that dials the address the server printed and sends a single line of text. The client is deliberately simple: it reads the address from the command line, opens a TCP connection, writes a greeting, then reads the server's reply and prints it. This mirrors how tailcat works, but we keep everything in plain Go so you can see each piece clearly.

client.go

package main

import (
    "bufio"
    "fmt"
    "net"
    "os"
)

func main() {
    if len(os.Args) != 2 {
        fmt.Fprintf(os.Stderr, "Usage: %s <server-address>\n", os.Args[0])
        os.Exit(1)
    }
    addr := os.Args[1]

    conn, err := net.Dial("tcp", addr)
    if err != nil {
        fmt.Fprintf(os.Stderr, "dial error: %v\n", err)
        os.Exit(1)
    }
    defer conn.Close()

    // Send a single test line.
    fmt.Fprintln(conn, "hello from tailcat‑clone")

    // Read the server's reply.
    scanner := bufio.NewScanner(conn)
    for scanner.Scan() {
        fmt.Printf("REPLY: %s\n", scanner.Text())
    }
    if err := scanner.Err(); err != nil {
        fmt.Fprintf(os.Stderr, "read error: %v\n", err)
    }
}
4

Phase 4: Run and test locally

Open two terminal windows (or tabs). In the first one start the server binary; it will print a Tailscale‑reachable address like LISTEN 100.101.102.103:12345. Copy that address. In the second terminal run the client binary, passing the copied address as its argument. You should see the client print the server's reply and then exit.

# Terminal 1: start the server (assumes server.go already exists)
go run server.go &
# Wait a moment for the server to print its address, then copy it.

# Terminal 2: run the client with the printed address
go run client.go <copied-address>
5

Phase 5: Verify and extend

When the client finishes you should see a line like REPLY: hello from tailcat‑clone in its output. That proves the encrypted Tailscale tunnel is working end‑to‑end. From here you can replace the hard‑coded greeting with data from stdin, loop to forward a whole file, or wrap the logic in a small CLI that accepts flags for address and message.

# Quick verification that the round‑trip succeeded
go run client.go $(go run server.go | grep -oE "[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+:[0-9]+")
