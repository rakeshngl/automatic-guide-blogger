Simple AI Coding Assistant Clone

A minimal local web app that accepts code prompts and returns mock AI suggestions

Welcome to another official UVF IT guide where we demystify building a tiny AI‑powered coding assistant inspired by Contral. In just ~45 minutes you’ll have a runnable Node.js + SQLite prototype that accepts a coding question and replies with a canned “AI” answer, all running locally on your machine.

We’ll use only free, open‑source tools—Node.js, Express, and better‑sqlite3—so you won’t need any paid API keys. The real Contral checks code with LLMs; our clone simulates that step with a simple template, giving you a solid foundation to plug in any model later.

Before You Start

  • You need Node.js ≥ 18 and npm installed; older versions may lack ES‑module support.
  • The AI response is mocked; to integrate a real LLM you’ll replace the placeholder function with an API call or local model.
  • SQLite stores prompts locally; in production you’d use a proper DB and authentication.

Phase 2: Data Model (SQLite)

We need a tiny persistence layer to remember each prompt and the mock AI reply. Using better‑sqlite3 we can create a lightweight SQLite file and expose a few helper functions.

The table prompts stores the original user query, the generated answer, and timestamps – enough for a prototype and easy to extend later.

db.js

import Database from 'better-sqlite3';

// Initialise (or open) a local SQLite file
const db = new Database('assistant.db');

// Create prompts table if it doesn't exist yet
const init = `
CREATE TABLE IF NOT EXISTS prompts (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  query TEXT NOT NULL,
  answer TEXT NOT NULL,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
`;
db.exec(init);

/**
 * Save a prompt/answer pair.
 * @param {string} query  User's code question
 * @param {string} answer Mock AI response
 * @returns {number} Inserted row id
 */
export function savePrompt(query, answer) {
  const stmt = db.prepare('INSERT INTO prompts (query, answer) VALUES (?, ?)');
  const info = stmt.run(query, answer);
  return info.lastInsertRowid;
}

/** Retrieve all stored prompts for display or debugging */
export function getAllPrompts() {
  return db.prepare('SELECT * FROM prompts ORDER BY created_at DESC').all();
}

export default db;

Phase 3: Core API & Mock AI

We’ll add a tiny Express server that listens on port 3000. It exposes a /api/ask POST endpoint which receives a JSON body with a prompt field, creates a canned response, stores the interaction in memory, and returns the result as JSON. Keeping everything in one file makes it easy to run and extend later, and the in‑memory store mimics a tiny database without extra setup.

server.mjs

import express from 'express';
import cors from 'cors';
const app = express();
app.use(cors());
app.use(express.json());
app.use(express.static('public'));
let history = [];
function mockAI(prompt){
  return `You asked: "${prompt}". Here is a mock suggestion.`;
}
app.post('/api/ask', (req,res)=>{
  const {prompt}=req.body;
  if(!prompt){return res.status(400).json({error:'Prompt required'});}
  const answer=mockAI(prompt);
  const entry={prompt,answer,ts:Date.now()};
  history.push(entry);
  res.json(entry);
});
app.get('/api/history', (req,res)=>res.json(history));
const PORT=process.env.PORT||3000;
app.listen(PORT,()=>console.log(`🚀 http://localhost:${PORT}`));

Phase 4: Simple UI

Now we create a minimal front‑end that talks to the API. The page contains a textarea for the user’s prompt, a Send button, and a div where the AI’s reply will appear. When the button is clicked we POST the prompt to /api/ask, then render the JSON response below the form. All assets live in the public folder, which Express serves automatically.

public/index.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <title>Simple AI Coding Assistant</title>
  <style>
    body{font-family:sans-serif;margin:2rem;}
    textarea{width:100%;height:100px;}
    #reply{margin-top:1rem;padding:0.5rem;background:#f0f0f0;}
  </style>
</head>
<body>
  <h1>Ask the AI</h1>
  <textarea id="prompt" placeholder="Enter your coding question..."></textarea><br/>
  <button id="send">Send</button>
  <div id="reply"></div>
  <script>
    document.getElementById('send').onclick=async()=>{
      const prompt=document.getElementById('prompt').value;
      const res=await fetch('/api/ask',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({prompt})});
      const data=await res.json();
      document.getElementById('reply').textContent=data.answer;
    };
  </script>
</body>
</html>

Phase 5: Run & Verify

With the server and UI in place, start the development server using nodemon so code changes reload automatically. Open the displayed URL in a browser, type any question into the textarea, and hit Send – you should see the mock answer appear instantly. This confirms the full request‑response loop works locally without any external AI services.

npm init -y
npm install express cors nodemon
# add a start script in package.json
npx nodemon server.mjs
