Ghost‑Downloader‑3‑style File Downloader (Python)

A minimal clone you can build in 45 minutes

Welcome to another official UVF IT guide! In this quick build you’ll create a lightweight file‑downloader inspired by Ghost‑Downloader‑3, using only Python’s standard library and SQLite on the free tier. No paid APIs, no complex UI – just a command‑line tool that fetches files and records history.

We’ll scaffold a tiny Flask app, define a SQLite model for download logs, expose a simple JSON API, and run everything locally. By the end you’ll have a working downloader you can extend with proxy support or a front‑end.

Before you start…

  • You need Python 3.10+ installed and pip available; the guide uses only the standard library plus Flask (installed via pip).
  • The real Ghost‑Downloader‑3 includes multi‑threaded chunked downloads, proxy rotation and a rich GUI – this clone only downloads a single URL at a time and stores a basic log.
  • On Windows, ensure the venv scripts directory is in your PATH; otherwise activate the virtual environment with .venv\Scripts\activate.

Phase 2: Define the SQLite model

We need a small helper that ensures a downloads table exists and lets us record each download request. SQLite lives in a single file, so no server setup is required – perfect for a minimal clone.

The helper provides two functions: init_db() creates the table if needed, and log_download(url, path) inserts a row with the source URL, local filename, and timestamp.

model.py

import sqlite3
from datetime import datetime

DB_PATH = 'downloads.db'

def _connect():
    return sqlite3.connect(DB_PATH)

def init_db():
    """Create the downloads table if it doesn't already exist."""
    with _connect() as conn:
        conn.execute('''
            CREATE TABLE IF NOT EXISTS downloads (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                url TEXT NOT NULL,
                file_path TEXT NOT NULL,
                downloaded_at TEXT NOT NULL
            )
        ''')
        conn.commit()

def log_download(url: str, file_path: str):
    """Insert a log entry for a completed download."""
    with _connect() as conn:
        conn.execute(
            'INSERT INTO downloads (url, file_path, downloaded_at) VALUES (?,?,?)',
            (url, file_path, datetime.utcnow().isoformat())
        )
        conn.commit()

# Initialize the DB when the module is imported
init_db()

Phase 3: Build the Flask API & CLI downloader

We create a tiny Flask service that accepts a JSON payload containing a url. The server streams the remote file, writes it into a files/ directory, and records the filename, size and timestamp in a SQLite database. A small command‑line wrapper lives in the same file so you can test the endpoint locally without needing curl or a browser.

The CLI uses the same download logic as the API, which guarantees that both paths behave identically. This keeps the code base minimal while still showing how the original Ghost‑Downloader‑3 separates the download engine from the web layer.

app.py

import os, sys, argparse, sqlite3, requests
from flask import Flask, request, jsonify, send_file
from datetime import datetime

app = Flask(__name__)
DB_PATH = 'downloads.db'
FILES_DIR = 'files'
os.makedirs(FILES_DIR, exist_ok=True)

# ---------- SQLite helpers ----------
def init_db():
    conn = sqlite3.connect(DB_PATH)
    cur = conn.cursor()
    cur.execute('''CREATE TABLE IF NOT EXISTS downloads(
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        url TEXT,
        filename TEXT,
        size INTEGER,
        ts TEXT
    )''')
    conn.commit(); conn.close()

def log_download(url, filename, size):
    conn = sqlite3.connect(DB_PATH)
    cur = conn.cursor()
    cur.execute('INSERT INTO downloads(url,filename,size,ts) VALUES(?,?,?,?)',
                (url, filename, size, datetime.utcnow().isoformat()))
    conn.commit(); conn.close()

# ---------- Core download function ----------
def download_file(url):
    resp = requests.get(url, stream=True, timeout=15)
    resp.raise_for_status()
    fname = os.path.basename(url.split('?')[0]) or f"file_{int(datetime.utcnow().timestamp())}"
    fpath = os.path.join(FILES_DIR, fname)
    with open(fpath, 'wb') as f:
        for chunk in resp.iter_content(chunk_size=8192):
            if chunk: f.write(chunk)
    size = os.path.getsize(fpath)
    log_download(url, fname, size)
    return fpath, size

# ---------- Flask endpoint ----------
@app.route('/download', methods=['POST'])
def api_download():
    data = request.get_json(silent=True) or {}
    url = data.get('url')
    if not url:
        return jsonify({'status':'error','msg':'Missing url'}),400
    try:
        path, size = download_file(url)
        return jsonify({'status':'saved','filename':os.path.basename(path),'size':size})
    except Exception as e:
        return jsonify({'status':'error','msg':str(e)}),500

# ---------- CLI wrapper ----------
if __name__ == '__main__':
    init_db()
    parser = argparse.ArgumentParser(description='Download a file via the Flask API or locally')
    parser.add_argument('url', help='Remote file URL')
    parser.add_argument('--api', action='store_true', help='Send request to local Flask server instead of direct download')
    args = parser.parse_args()
    if args.api:
        import json, urllib.request
        req = urllib.request.Request('http://127.0.0.1:5000/download',
                                     data=json.dumps({'url':args.url}).encode(),'application/json')
        with urllib.request.urlopen(req) as resp:
            print(resp.read().decode())
    else:
        p, s = download_file(args.url)
        print(f'Downloaded {p} ({s} bytes)')

Phase 4: Run locally and test

Start the Flask server in one terminal; it will create the SQLite file and the files folder on first run. Then you can either invoke the built‑in CLI or use curl to hit the /download endpoint and watch the file appear on disk.

Both methods return a short JSON payload confirming the operation, making it easy to script further tests or integrate into other tools.

# Terminal 1: start the Flask API
python app.py &
# Give it a second to bind
sleep 1

# Terminal 2: test via CLI (direct download)
python app.py https://www.example.com/index.html

# Terminal 2: test via HTTP API using curl
curl -X POST -H "Content-Type: application/json" -d '{"url":"https://www.example.com/index.html"}' http://127.0.0.1:5000/download

Phase 5: Verify and extend

After the download finishes, look inside the files directory – you should see the saved file with its original name (or a generated fallback). Open the SQLite database to confirm a row was inserted with the URL, filename, size and timestamp.

From here you can easily add features: proxy support by passing a proxies dict to requests.get, multi‑threaded workers using concurrent.futures, or a tiny HTML page that posts to /download. The scaffold is deliberately simple so you can experiment without fighting legacy complexity.

# Verify file existence
ls -l files

# Verify SQLite log entry
sqlite3 downloads.db "SELECT id,url,filename,size,ts FROM downloads ORDER BY id DESC LIMIT 1;"
