Daily Stock Analysis Dashboard (Python Clone)

A beginner-friendly, free‑tier clone of an AI‑powered stock insight tool

Welcome to another official UVF IT build guide! In the next 45 minutes you’ll spin up a tiny Python dashboard that fetches daily stock prices, runs a simple prompt‑based analysis with an open‑source LLM, and displays the result in a web UI – inspired by the full‑featured Daily Stock Analysis system.

We’ll use Flask for the web layer, SQLite for persistence, and the free HuggingFace inference API for LLM calls, so you won’t need any paid keys.

Before you start

  • You need Python 3.10+ and git installed; the guide assumes a Unix‑like shell.
  • The real product uses paid LLM endpoints and multi‑channel push notifications – our clone only does a local text analysis.
  • Network calls to HuggingFace may be rate‑limited; if you hit a 429, wait a minute and retry.

Phase 2: Define the data model

A tiny SQLite table stores the ticker symbol and the latest price fetched from a free market API. SQLite lives in a single file, perfect for a lightweight clone, and Flask can access it with the built‑in sqlite3 module.

We also provide two helper functions: init_db() creates the table if it doesn’t exist, and save_price(symbol, price) upserts a row for the latest quote.

model.py

import sqlite3
from pathlib import Path

DB_PATH = Path(__file__).with_name('stocks.db')

def get_connection():
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row
    return conn

def init_db():
    """Create the stocks table if it doesn't exist."""
    with get_connection() as conn:
        conn.execute(
            """
            CREATE TABLE IF NOT EXISTS stocks (
                symbol TEXT PRIMARY KEY,
                price REAL NOT NULL,
                fetched_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
            )
            """
        )
        conn.commit()

def save_price(symbol: str, price: float):
    """Insert or update the latest price for a ticker."""
    with get_connection() as conn:
        conn.execute(
            "INSERT INTO stocks (symbol, price) VALUES (?, ?) "
            "ON CONFLICT(symbol) DO UPDATE SET price=excluded.price, fetched_at=CURRENT_TIMESTAMP",
            (symbol.upper(), price),
        )
        conn.commit()

def get_price(symbol: str):
    """Retrieve the most recent price for a ticker, or None if missing."""
    with get_connection() as conn:
        cur = conn.execute("SELECT price FROM stocks WHERE symbol = ?", (symbol.upper(),))
        row = cur.fetchone()
        return row["price"] if row else None

if __name__ == "__main__":
    init_db()
    # Quick sanity check
    save_price('AAPL', 172.34)
    print('Saved AAPL price:', get_price('AAPL'))

Phase 3: Core API & simple UI

In this step we wire up a tiny Flask server that does three things: fetch a live price, ask a placeholder LLM for a short insight, and store everything in a local SQLite database. The endpoint will then read the stored rows and render them in a very basic HTML table so you can see the data instantly in your browser. Keeping everything in one file makes it easy to follow and modify as you add more features later.

app.py

import sqlite3, requests, datetime
from flask import Flask, g, render_template_string

app = Flask(__name__)
DB_PATH = 'stocks.db'

# ---------- SQLite helpers ----------
def get_db():
    db = getattr(g, '_database', None)
    if db is None:
        db = g._database = sqlite3.connect(DB_PATH)
        db.row_factory = sqlite3.Row
    return db

@app.teardown_appcontext
def close_connection(exception):
    db = getattr(g, '_database', None)
    if db is not None:
        db.close()

def init_db():
    with app.app_context():
        db = get_db()
        db.execute('''CREATE TABLE IF NOT EXISTS price (
                        id INTEGER PRIMARY KEY AUTOINCREMENT,
                        symbol TEXT,
                        price REAL,
                        insight TEXT,
                        ts TEXT)''')
        db.commit()

# ---------- Simple LLM placeholder ----------
def get_insight(symbol, price):
    # In a real clone you would call an LLM here. We'll just return a static string.
    return f"{symbol} is currently at ${price:.2f}. Keep an eye on market trends."

# ---------- Price fetcher ----------
def fetch_price(symbol):
    # Using a free public API (Yahoo Finance) for demo purposes.
    url = f"https://query1.finance.yahoo.com/v7/finance/quote?symbols={symbol}"
    resp = requests.get(url).json()
    return float(resp['quoteResponse']['result'][0]['regularMarketPrice'])

# ---------- Main route ----------
@app.route('/')
def index():
    symbols = ['AAPL', 'TSLA']  # you can add more symbols here
    db = get_db()
    for sym in symbols:
        price = fetch_price(sym)
        insight = get_insight(sym, price)
        ts = datetime.datetime.utcnow().isoformat()
        db.execute('INSERT INTO price (symbol, price, insight, ts) VALUES (?,?,?,?)',
                   (sym, price, insight, ts))
    db.commit()
    rows = db.execute('SELECT * FROM price ORDER BY ts DESC').fetchall()
    html = '''<h1>Daily Stock Analysis</h1>
              <table border="1" cellpadding="5"><tr><th>Symbol</th><th>Price</th><th>Insight</th><th>Timestamp</th></tr>
              {% for r in rows %}<tr><td>{{r.symbol}}</td><td>{{"$%.2f"|format(r.price)}}</td><td>{{r.insight}}</td><td>{{r.ts}}</td></tr>{% endfor %}
              </table>'''
    return render_template_string(html, rows=rows)

if __name__ == '__main__':
    init_db()
    app.run(debug=True)

Phase 4: Run locally

Now that the Flask app is ready, start it with a single command. The server will listen on the default port 5000 and automatically reload when you edit the file, which is handy while you experiment. Open your browser to the shown address and you should see a table populated with the two ticker symbols.

python app.py
